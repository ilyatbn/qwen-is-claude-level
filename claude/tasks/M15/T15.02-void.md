# T15.02 — The floor can be dug through, and below it is death (v4)

Milestone: M15 · Depends on: T15.01 · Size: ~180 lines

## Read first
- `docs/72-amendments-v4.md` §C15
- `docs/11-map-destruction.md` §2 (bedrock clamping)

## Deliverable

`BEDROCK_H` 24 → **0**, replaced by a destructible `FLOOR_CRUST` (16). Below the map
is void: a body whose top edge passes `y = h` **dies immediately**, attributed to
`DamageSource::Void`, scoring `DEATH_POINTS` like any death. Projectiles and world
items that pass `y = h` despawn.

Walls stay indestructible — §A1's hard limits on x are unchanged.

## Notes

- **Do this after T15.01.** Indestructible pads are what keep a dug-through map
  playable; without them a map with no floor has nowhere to respawn, which is the
  bug this milestone started from.
- `carve_circle`'s bedrock clamp is load-bearing and bit-exact (`docs/11` §2). Changing
  what it clamps changes generated masks — **regenerate the golden table and re-run
  the 999-seed sweep**, reporting the new attempt distribution, as T9.04 did.
- The traversal validator must treat the void as a **hazard, not a wall**: falling in
  is a legitimate death, not a validation failure. Check whether it currently counts
  the bedrock row as walkable ground.
- Fall damage is deliberately absent in v1 (`docs/20` §9); the void is not fall
  damage, it is a boundary.

## Tests

- A carve at the bottom now removes pixels where it previously removed none, at every
  scale.
- A body falling past `y = h` dies exactly once, with the right cause and score.
- A projectile and a world item past `y = h` despawn rather than accumulating.
- Golden table regenerated deliberately, and the 999-seed sweep still passes with its
  numbers reported.
- A map dug through to the void still has 6 standable pads (the T15.01 guarantee).
