# T20.17 — The tests that never run (v8)

Milestone: M20 · Depends on: nothing · Size: unknown — **survey first**

**Booked by the coordinator's ruling in `HANDOFF-M20.md`**, from T20.16's diagnosis.

## What was seen

`balance.rs`'s control eroded from 1/8 of margin to 0 across **nine milestones**, invisibly,
because it is `#[ignore]`d and nothing ever runs it. Its own comment claimed a margin it did
not have. Nobody was negligent — **there is no mechanism by which anyone would have noticed.**

That is `HANDOFF-M19`'s through-line — *an instrument is only valid for the code it was
written against, and nothing re-validates it* — recurring in the one class of test the gate
never executes.

## The survey is the first deliverable

**Do not design a fix before you know the size of the problem.** Enumerate every `#[ignore]`d
test in the workspace and, for each: what invokes it, if anything; when it last ran, if that
is knowable; and whether its assertions carry a margin that could erode silently.

`density_report` is a known second instance — M19 recorded it as *"red at the base commit and
green after, drift across a marginal threshold, not a fix"*. Expect more.

## Then choose, and say why

Candidates, none pre-chosen:
- a **periodic** run (a separate command, a schedule, or a milestone-boundary ritual);
- a **cheaper variant inside the gate** — fewer seeds, debug build — that would catch erosion
  without the minutes;
- an explicit **"re-measure when X changes"** marker per test, so the trigger is written down
  even if the run is not automated.

The third is the weakest and the cheapest; **if you choose it, say plainly that it relies on
somebody reading it.**

## Notes

- **A measurement that takes minutes is not thereby exempt.** The cost is why it is
  `#[ignore]`d; the erosion is the price already paid for that.
- Anything added to the gate must not make it slower in a way that gets it skipped — a gate
  people avoid running is a gate that gates nothing.

## Tests

- Whatever lands, **demonstrate it catches an erosion it would previously have missed** —
  plant a drift and show the mechanism fires. Without that this task ships a process nobody
  can tell is working.
