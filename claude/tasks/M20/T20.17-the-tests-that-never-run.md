# T20.17 — The tests that never run (v8)

Milestone: M20 · Depends on: nothing · Size: unknown — **survey first**

**Booked by the coordinator's ruling in `HANDOFF-M20.md`**, from T20.16's diagnosis.

## What was seen

`balance.rs`'s control eroded from 1/8 of margin to 0 across **nine milestones**, invisibly,
because it is `#[ignore]`d and nothing ever runs it. Its own comment claimed a margin it did
not have. Nobody was negligent — **there is no mechanism by which anyone would have noticed.**

That is `HANDOFF-M19`'s through-line — *an instrument is only valid for the code it was
written against, and nothing re-validates it* — recurring in the one class of test the gate
never executes.

## The survey is done — 13 tests, no runner, no CI

Counted read-only, so **verify before relying on it**:

- `crates/game-core/tests/balance.rs` — 5 (`balance_report`, `density_report`,
  `the_shipping_configuration_produces_a_fight`, `encounter_report`, `item_population_report`)
- `crates/game-core/src/map/gen/silhouette.rs` — 2
- `crates/game-core/src/map/gen/mod.rs` — 2
- `crates/game-server/tests/capacity.rs` — 2
- `crates/game-core/tests/map_sweep.rs` — 1
- `crates/game-core/src/bots/mod.rs` — 1 (`kill_chain`)

**Nothing runs any of them.** `scripts/check.sh:35` is `cargo test --workspace` — no
`--release`, no `-- --ignored`; `grep -- "--ignored" scripts/ Makefile` returns **0**; and
**there is no `.github/` directory**, so there is no CI. A human typing `./scripts/check.sh`
is the entire gate. Every `--ignored` command line in the repo lives in markdown, to be
copy-pasted by hand. `docs/60-testing.md` says nothing about ignored tests.

## The class is not "reports" — at least three are real regression guards

This is what changes the shape of the task:

- **`map/gen/mod.rs:238 fifty_medium_seeds_pass_without_the_safe_preset`** — its own comment
  is *"The tuning gate. If this fails, the generation parameters need adjusting — **report it
  rather than loosening the assertion**."* Two `assert_eq!`s: the safe preset must never be
  needed across 50 seeds, and no seed may need more than 3 attempts. **A correctness claim
  about every map the game generates, unrun for nine milestones.**
- **`capacity.rs:313 rooms_do_not_get_more_expensive_as_more_are_added`** — eight rooms must
  cost under 3× one room, because *"a super-linear result would mean something is shared that
  should not be."* **Rooms were touched repeatedly this milestone** — T20.01's sweep, T20.13's
  two-room path, the reaper.
- **`balance.rs:873`** — the one already known red.

`solid_fraction_sweep_medium` (13 asserts) and `kill_chain` (6) are unclassified; classify
them.

## Then choose, and say why

**Start from the pattern the repo already has**, not a blank page: `capacity.rs:335
max_rooms_carries_its_basis` is **not** ignored and exists precisely to pin the *claim* an
unrun measurement makes — *"This does not re-run the benchmark — it pins the claim the
constant's doc comment makes, so changing the number without re-measuring is visible in the
diff."* Its own history is the lesson: a first version accepted the string `"T10.07"`, which
the placeholder *"Provisional until T10.07 measures it"* already contained, so it passed
against exactly the text it was meant to catch. It checks for **numbers** now.

**A gate-resident companion per ignored measurement, asserting the numbers its doc comment
claims, is a fourth candidate and probably the strongest** — it is cheap, it is already
proven here, and its falsification has already been paid for.

Other candidates, none pre-chosen:
- a **periodic** run (a separate command, a schedule, or a milestone-boundary ritual);
- a **cheaper variant inside the gate** — fewer seeds, debug build — that would catch erosion
  without the minutes;
- an explicit **"re-measure when X changes"** marker per test, so the trigger is written down
  even if the run is not automated.

The third is the weakest and the cheapest; **if you choose it, say plainly that it relies on
somebody reading it.**

## Notes

- **A measurement that takes minutes is not thereby exempt.** The cost is why it is
  `#[ignore]`d; the erosion is the price already paid for that.
- Anything added to the gate must not make it slower in a way that gets it skipped — a gate
  people avoid running is a gate that gates nothing.

## Tests

- Whatever lands, **demonstrate it catches an erosion it would previously have missed** —
  plant a drift and show the mechanism fires. Without that this task ships a process nobody
  can tell is working.
