# T23.05B — The generator's cave mask on the client (R17)

Milestone: M23 · Depends on: T23.05 · Size: ~200 lines · Rulings: R3, R4, R17

R17: the cave wall is air that was rock **in the generator's landform** or at round start. `render_fields.rs` already
takes the "was rock" mask as an input (`GameCore::render_fields_full_with_wall(bytes)`, one byte per px); today only
the round-start half is fed, so generated caves still read as sky. This task supplies the other half.

## The choice, and why (checked 2026-09-25, T23.05's builder)
`map_init` (`game-server/src/codec.rs::encode_map_init_at`) already carries the **seed, scale and generator byte**
beside the mask RLE, and generation is deterministic from them (`golden.rs::generated_masks_match_the_golden_table`
pins it). So the client can **re-derive** the landform instead of receiving it: no wire change, no bandwidth, no
server change. Shipping it as a second RLE would double `map_init` for data the client can compute. **Re-derive.**

What re-deriving needs, and the checks it owes:
1. `game-core`: the generator records the union of what its carve passes removed (`gen/mod.rs`: `carve_network`,
   `carve_caves`, `carve_crevices`, `carve_voids`, and the space generator's equivalents) and returns it beside the
   `Map` from a new entry point — **without changing the `Map` it returns**. R3: `golden.rs` untouched and green is the
   proof.
2. Confirm first that `map_init`'s seed is the seed that **reproduces** the map (`generate_with_secret` takes a
   *requested* seed; if it re-rolls, the carried seed must be the final one) — generate from `map_init`'s fields and
   assert mask equality with the received RLE, on every scale and generator. If it is not reproducible, fall back to
   the RLE option and say why.
3. `game-wasm`: after `load_mask`, derive the landform from the carried fields and call
   `render_fields_full_with_wall`. Cost: one generation (< 1 s on Medium, `medium_generation_is_under_a_second`) at
   round start, in the loading screen.

## Tests
- Landform ⊇ final mask, and landform ∧ ¬mask is non-empty on every scale (the caves exist) — 20 seeds.
- Re-derived from `map_init`'s fields == the server's (mask equality, above), all generators.
- `golden.rs` untouched.

## As built (builder, 2026-09-27)
- **Re-derived, exact.** `map_init`'s seed is `MapMeta.seed` = the attempt that *passed* (not the requested one); the
  theme byte is `theme_for(requested)`. `gen::rederive(seed, scale, generator, theme)` runs the default params at that
  seed and falls back to the safe preset only if that attempt fails — which is exactly when the server used it (attempt
  0 at `requested` failed). `map_init_fields_rederive_the_servers_landform`: 8 seeds × 3 scales × v1/v2/space, mask and
  landform equal the server's, 3 of the 72 maps retried; control `the_requested_seed_does_not_rederive_a_retried_map`.
  The safe-preset branch is unexercised (no sweep has ever hit it) — stated, not tested.
- **Landform = pre-carve mask ∪ final generator mask** (`GenOutcome.landform`; not in `Map`, golden untouched). Space
  carves nothing: landform = mask. Wall = landform ∪ the mask at the full pass (R17).
- **Wasm:** `render_fields_full_landform(seed_lo, seed_hi, scale, generator, theme)` (networked) and
  `render_fields_full_own_landform()` (sandbox/preview), landform cached by those fields (a resync of the same map is
  free). No `lib.rs` change was needed; no wire, replay or server change.
- **Cost, wasm release in node, seed 12161:** v2 (default) derive S/M/L ≈ 19–82 / 190–201 / 407–414 ms; v1 266 / 592 /
  1098 ms; the full field pass beside it 200–270 / 450–490 / 705–953 ms. Native release worst: v2 L 380, v1 L 816, space
  L 42 ms. T23.06 owns keeping this off the frame.
