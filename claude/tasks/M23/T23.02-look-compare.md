# T23.02 — `look-compare`: the instrument, and its must-fail controls

Milestone: M23 · Depends on: T23.01 · Size: ~250 lines · Rulings: § Verification

An instrument first proves it can fail. This task builds the comparison and shows it separating what must pass
from what must fail **before** any renderer exists to flatter it.

## Do
1. `scripts/lib/look-compare.mjs`: given two 1280×720 PNGs and optional region masks, report
   SSIM on luminance at ½ scale, per-region mean ΔE2000 (regions: sky, terrain, actor boxes — boxes come from the
   scene description), luminance histogram distance (Wasserstein), p5/p50/p95 luminance, 8-colour k-means palette
   mean ΔE, saturation histogram, edge density, fraction above the bloom threshold. Plain JS with `pngjs` (already a
   dependency — check). **FLIP**: wrap `flip-evaluator` if `python3 -c "import flip_evaluator"` succeeds; if it is not
   installed, say so in the output and skip — never report a FLIP number that was not computed.
2. **Controls, rendered with the mockup harness** (scratch copy of `reference/mockup-src`): F1 twice (floor), F0 vs
   F1, and F1 with exposure ±10 %, bloom off, rim off (`lit()` without its rim passes), fog off, F2's palette. Save the
   control PNGs under `tasks/M23/reference/controls/` so later checks compare against the same files.
3. Write each metric's floor and its smallest failing control into `scripts/lib/look-thresholds.json`, with the
   threshold between them. **If a metric does not separate the floor from every control, drop it** and say so —
   a metric that cannot fail is the thing CLAUDE.md forbids.

## Tests
- node test: `look-compare` on the same image twice → identical; on F0 vs F1 → every retained metric fails its
  threshold; on each single-knob control → at least one retained metric fails. Print the table.

## Touch only
new `scripts/lib/look-compare.mjs` (+ test), new `scripts/lib/look-thresholds.json`, `tasks/M23/reference/controls/`,
`tasks/`

## Done when
`node --test scripts/lib/look-compare.test.mjs` exits 0 and the floor/control table is in the journal.
