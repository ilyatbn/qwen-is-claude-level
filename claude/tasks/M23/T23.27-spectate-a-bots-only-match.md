# T23.27 — Spectate a bots-only match; Tab switches who you watch

Milestone: M23 · Owner ask 2026-09-30 · Size: ~300 lines, server + client · Pairs with T23.26 (how the owner judges it)

> *"simulate a game with bots only with a full chrome ui so i can watch and comment. let me switch the camera between
> them (like a spectate mode) with tab."*

## Do
- **Server: a spectator seat.** A join flagged `spectate` takes a seat with **no body**: not in `world.players`, not
  counted toward `MAX_PLAYERS` or the round's "last one standing", sends no input, receives every snapshot/event a
  player does. A room whose humans are all spectators still starts with bots (`start_with_bots` / the lobby timeout).
  Unflagged joins behave exactly as today (wire-compatible; an old client never sends the flag).
- **Client: `?spectate=1`** joins that way. The camera follows a chosen living player (`world.rig.follow`), starting
  with the first; **Tab = next living player, Shift+Tab = previous** (in spectate mode only — Tab keeps the scoreboard
  in a normal match; in spectate the scoreboard moves to a held key and says which). When the watched one dies, stay
  on their death for ~1 s then move to the next. The HUD shows **the watched player's** name, health, energy, jet and
  weapon, and a small "SPECTATING <name> — Tab to switch" line. No crosshair, no inventory input. The kill feed,
  minimap and night view work as for a player (night view centred on the watched one).
- **`make watch`**: release server with `BOT_COUNT=6` (full room), vite, and a headed GPU Chrome (`scripts/play.mjs`) on
  `?spectate=1` — the owner's one command. Optional `WATCH_ENV` passes e.g. `DEV_BOT_FRENZY=1 DEV_LOADOUT=1`.

## Tests
- server: a spectator join is not in the world, does not block a round from ending, receives snapshots; an unflagged
  join still gets a body (control).
- a browser check `spectate`: joins spectating a bots-only room, asserts the camera centre sits on player A, presses
  Tab, asserts it moved to player B (pixel or `debug().watching` + camera centre, **both ends**), and that no body
  belongs to the spectator.

## Touch only
`crates/game-server/src/{session,room,codec}.rs` (+ tests), `client/src/scenes/GameScene.ts`, `client/src/net/**`,
`client/src/ui/**` (HUD/scoreboard), `client/src/input/**`, `scripts/checks/spectate.mjs`, `scripts/lib/e2e-checks.mjs`,
`scripts/lib/affected.mjs` (map the new check), `Makefile`, `tasks/`

## Done when
`cargo test -p game-server && node scripts/e2e.mjs --only spectate` exits 0, plus `./scripts/check.sh --changed`, and
`make watch` opens a window the owner can Tab through.
