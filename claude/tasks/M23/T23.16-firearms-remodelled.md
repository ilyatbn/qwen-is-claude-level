# T23.16 — The firearms, remodelled

Milestone: M23 · Depends on: T23.14 (and F6 in `reference/`) · Size: ~250 lines · Rulings: R10, R12

**Today 21 of 24 holdable weapons draw nothing in the hand** (`weaponTextures.ts::WEAPON_ART` covers bazooka, grenade,
smg; `PlayerView.setWeapon` draws a 0×0 rectangle for the rest). This task and T23.17 give every one a silhouette.

## Do
1. Held models, in F6's ink-silhouette style, drawn by code into the actor cell with the figure's aim, for:
   bazooka (0), smg (2), laser_pistol (5), laser_smg (6), pistol (7), revolver (8), deagle (9), machinegun (10),
   flamethrower (16), platform_gun (26 — the turret, `e_style.js::turret`). Muzzle point and pivot per weapon as
   named constants (today duplicated in `skins.json weapons[]` — one home now).
2. Each weapon's glow parts in the B channel (laser tip, muzzle), so the rim shader lights them (T23.13).
3. **Ground pickups and inventory icons** come from the same drawing functions (R12) — one design per weapon, not
   three. Retire `weaponTextures.ts` and the `items` atlas frames these replace; `itemTextures.ts` keeps only what
   T23.17/T23.19 still need.
4. **Readability, measured:** at game scale (zoom 1), no two firearms' silhouettes are more similar than a threshold
   (IoU of their ink masks at the same aim) — pick the threshold from the data and state the most-similar pair.

## Tests
- vitest: every holdable firearm id has a model (count both ends: the ids in `items/registry.rs` that are firearms vs
  the model table's keys).
- Browser check `weapons-held`: look-lab F6 vs F6 (Level A per weapon box); live: switching weapon changes the hand
  patch (each of the ten), with the body patch as the control.
