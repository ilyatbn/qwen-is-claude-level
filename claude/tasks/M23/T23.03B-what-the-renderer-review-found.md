# T23.03B — What the renderer review found

Milestone: M23 · Depends on: T23.03, T23.02, T23.05 · Size: ~350 lines over several files (a review's findings, one commit
per area) · Rulings: R14, R18, R19, R20 (coordinator, 2026-09-26 — written into `M23-art.md`)

The T23.03 review (`gate-review2303-*.txt` in the repo root) planted three bugs into the world renderer and two of them
stayed green; it also found the resolution, the tier default and the look-compare thresholds resting on choices nobody
had ruled on. The coordinator ruled (R18–R20) and listed the fixes below.

## Do
- **R18 — resolution.** The world renders at **Phaser's game resolution**: pixel ratio = Phaser game width / canvas CSS
  width × tier scale, never `devicePixelRatio` — the mockup's `setPixelRatio(1)` at 1280×720. Effects sized in buffer
  pixels then match the references. State the memory at 4K.
- **R19 — look-compare's must-fail set** = {F0 vs F1, exposure ±10 %, bloom off, fog off}; each threshold sits between
  the measured floor and the smallest of that set. Rim-off is reported as a separate, non-gating sensitivity line.
  Re-derive `look-thresholds.json` from the zero floor now (T23.08 re-derives once the two-backend floor exists);
  update the doc and the node test.
- **R20 — quality tier.** `ui/settings.ts::qualityTier()` auto-detects when the player has never chosen: full on a real
  GPU renderer string, low on swiftshader / llvmpipe / software — read from three's own context
  (`renderer.getContext()`). An explicit toggle always wins; the stored value gains an "unset" state (not a new flag).
  Auto-detect never writes the High Quality flag (it still gates today's Phaser shader layers). The browser checks keep
  naming their tier explicitly (low). vitest for every state.
- **F1 (HIGH)** — `world-canvas` could not see a missed vertical invalidation (dropping `v.y === view.y` from the skip
  stayed green). Each probe sample carries Phaser's `cameras.main.worldView`; every frame asserts it equals the view
  last drawn; both pans get a vertical leg; one tested `sameView()`; plant red.
- **F2** — resize invalidation unguarded: a `setViewportSize` step with the camera still, reading pixels; plant red.
- **F3** — the redraw skip is conditional on an `animated` predicate over the layers (T23.04's stars cannot freeze); vitest.
- **F5** — `syncBox` reads `getBoundingClientRect` (fractional CSS boxes).
- **F6** — the ortho view is derived from `scrollX/scrollY/zoom/midPoint` without Phaser's integer rounding (dropping
  `pixelArt` later — R15 — must not jitter); today's pixels stay identical (`roundPixels` on) — test both.
- **F9** — `render_fields`: a wrong-length wall and `dirty()` before any snapshot are observable (a `Result`), not silent;
  a wasm-target timing of a crater update on Medium and a Large full pass, in ms. Note for T23.07: the
  `render_fields_ptr` view must be rebuilt after every call (memory growth).
- **F10** — `look/worldRenderer` is loaded by dynamic `import()` from `GameScene`, `SandboxScene` and `LookScene`, so the
  title and menu do not pay three.js's ~480 kB. Report the chunk sizes.
- **Stub** — the `StubRenderer` fallback fails `look-lab` by name (it passed with any backend).
