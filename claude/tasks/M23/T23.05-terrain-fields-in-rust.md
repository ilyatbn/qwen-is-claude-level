# T23.05 — Terrain fields in Rust: distance, cave-back and relief, per dirty rectangle

Milestone: M23 · Depends on: nothing (pure Rust) · Size: ~250 lines · Rulings: R3, R4

The terrain shader reads four derived channels (`mockup-src/kit.js::fieldTextures`): `dIn` (distance into rock),
`dOut` (distance from rock), `back` (carved-out rock = cave wall) and `relief`. They are computed from the mask,
which the simulation owns and this task must not change.

## Do
1. A **render-only** module in `game-wasm` (`crates/game-wasm/src/render_fields.rs`) — **not** `game-core`; it is not
   simulation and must never be read by it. Exact Felzenszwalb squared-distance transform (as `world.js::derive`),
   stored ×4 in 8 bits, **saturating at 64 px** — the mockup's exact encoding, so the shader constants port unchanged.
2. `back`: the same definition `render/chunkBake.ts::BackdropMask` uses today (confirm the two agree; if they differ,
   the mockup's definition wins for the picture and the difference is reported).
3. `relief`: port `world.js`'s relief (boulders, strata ledges) bit-exact, including its integer hash.
4. **Incremental update**: given a dirty rectangle (a carve's bounds), recompute only rect + 64 px, reading a +128 px
   margin, into a caller-owned RGBA8 world buffer. Expose `GameCore::render_fields_full()` and
   `render_fields_dirty(x, y, w, h)` returning the rect written.
5. Measure: full field at Small/Medium/Large and a radius-60 crater update, release build, in a `#[ignore]` bench
   with its numbers pasted (research estimated ~0.1 s and ~1–3 ms — **estimates, not measurements**).

## Tests
- `dIn`/`dOut` equal a brute-force nearest-pixel search on random masks (several seeds, several sizes).
- **Incremental equals full**: carve random circles, update incrementally, compare with a from-scratch full pass —
  byte-identical, across 20 seeds. Falsify by shrinking the margin to +32 px and watch it go red.
- `relief` matches values dumped from the mockup's `world.js` for `ARENA_E` (dump them with the mockup harness into
  a small fixture; cite how in the test).
- `golden.rs` untouched (R3).

## Touch only
new `crates/game-wasm/src/render_fields.rs`, `crates/game-wasm/src/lib.rs`, a small fixture file, `scripts/ignored.sh`, `tasks/`

`cargo test -p game-wasm && cargo test -p game-core golden` exits 0 and the bench numbers are in the journal.
