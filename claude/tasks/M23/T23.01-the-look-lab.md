# T23.01 — The look-lab: the renderer's input, fed from the reference scenes

Milestone: M23 · Depends on: T23.00 · Size: ~250 lines · Rulings: R1, R11

Everything that follows is measured against the pictures, so the thing that reproduces them comes first.

## Do
1. **Define the renderer's input as types** (`client/src/look/scene.ts`): the scene description the mockup builds —
   mask + back mask (as the game has them: `Uint8Array` W×H), actors (kind, position, pose/aim/weapon, colour, flags),
   lights `{x, y, z, r, rgb, i}`, palette `P` (every field `variant_F1.js` passes: `bg`, `terrain`, `fogBack`,
   `fogFront`, `fg`, `moon`, team colours, effect colours, `bloom`, `grade`, `exposure`), camera rect.
   Read `reference/mockup-src/f_scene.js`, `variant_F*.js`, `f_kit.js::frame` for the exact shape.
2. **Port the reference scenes as data**: F1 (`combatF` with `variant_F1`'s `P`), F2, F3, F4, and F5 when it
   exists — the same map (`maps.js::ARENA_E` through `world.js::buildMask`), actors, lights and palettes, as TS data
   modules under `client/src/look/scenes/`. **The mockup draws with absolute coordinates on a 1280×720 map strip at
   zoom 1; keep that.**
3. **A `?look=F1` page** (dev surface, like the sandbox) that builds the scene description and hands it to a
   renderer interface with a stub implementation (draws nothing yet). `window.__look.ready` flips when a frame is done.
4. **Noise floor**: re-render F1–F4 twice with the mockup harness (copy `reference/mockup-src` to a scratch dir)
   and record the pixel difference between runs; it should be zero or near it. Paste the numbers.

## Tests
- vitest: each ported scene's actor and light counts equal the mockup's (count both ends — read the mockup files'
  literal counts in the test's comment, then assert against the ported module); `P` for F1 has every field the
  mockup reads (a missing field would silently default).
- The page loads with `?look=F1` and reports `ready`.

## Touch only
new `client/src/look/**`, `client/src/main.ts` (route only), `scripts/checks/look-lab.mjs`, `scripts/lib/e2e-checks.mjs`,
`tasks/`

## Done when
`npm --prefix client run test -- --run && node scripts/e2e.mjs --only look-lab` exits 0, and the noise-floor numbers
are in the journal.
