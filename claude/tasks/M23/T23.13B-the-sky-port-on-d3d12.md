## Findings (builder, 2026-10-03) — sky fixed; Done-when NOT met on F1 world (terrain, see below)

Instrument: mockup rendered on D3D12 (headed google-chrome, `GALLIUM_DRIVER=d3d12`; `castonly.js` F4 + `flatpatch.js`
reproduces `controls/F4-cast-d3d12.png` byte-exact) against the lab on D3D12, per layer with new lab knobs
`stars-off` / `grain-off` (`LookScene.ts`) and the same switches in a scratch copy of `bgMaterial`.
F4 world, lab vs mockup, both D3D12: all on 0.0940 · stars off 0.0939 · grain off 0.0156 · both off 0.0155.
**Layer: the sky's per-pixel grain** (`col += (hash12(p) − 0.5)·grainK`). Not precision, not half targets.
**Cause:** the hash's *input* is compiled differently. Read back on the GPU (scratch harness with the lab's captured
composite source beside `bgMaterial`): the mockup's own in-context hash differs from the same hash in isolation on
434 328 px; it equals `hash12(vec2(vUv.x, 1.−vUv.y)*vec2(1280.0, 720.0))` exactly (0 px), and the lab's uniform-`RES`
form never does (the D3D12 compiler folds the *literal* size into the hash's constants; with a uniform it cannot).
**Fix:** `skyMaterial.ts` COMPOSITE grain reads `vec2(vUv.x, 1.-vUv.y)*GRAIN_RES`, `GRAIN_RES` a define of the frame
size as literals (`grainRes`, re-set in `place`). SwiftShader lab frame byte-identical before/after.
