# T23.04C — One renderer for the page; what the T23.04/T23.04B review found

Milestone: M23 · Depends on: T23.04B · Size: ~300 lines (split by finding) · Rulings: R22 (new), R21, R14, R20

## Why
The review of T23.04/T23.04B cycled title ↔ match ten times on one page (`gate-review2304-probe3.txt`):
`WorldRenderer.destroy()` disposed three's resources but never released the WebGL context, and every scene start
(the title since T23.04, every match and rematch) built a new `WebGLRenderer`. Live contexts 5 → 16, GPU-process
memory 343 → 933 MB, and at 17 Chrome drops the oldest context — in round 7 that was **Phaser's own** ("WebGL
Context lost. Renderer disabled"): a white page. Plus six smaller findings (F2–F8 below).

## Do
1. **R22 / F1 (blocker): one three.js `WebGLRenderer` for the page's lifetime.** Created by the first scene that
   draws the world; its canvas is re-parented under that scene's Phaser canvas and taken off the page when the
   scene shuts down. Scene-owned resources (sky bakes, post targets, materials, geometries) are created and
   disposed per scene. The throwaway probe canvas in `webgl2.ts` releases its context (`WEBGL_lose_context`);
   tier detection reads the shared renderer's context (no probe of its own).
2. **F2:** explosion-shader keeps black/white as coverage diagnostics and gains a **gating floor on the world
   canvas as drawn** (≥ the measured unplanted count, basis in the check). Plant: the blast fragment × 0.2 → red.
   Note the dark-on-dark readability problem in T23.08's and T23.18's task files.
3. **F3:** world-canvas's waits on `__world.frames() > 2` starve on a still camera (the redraw skip): wait on
   `__world.readFrame()` (invalidate + resolve on a drawn frame), then on Phaser's drawn frames. The match wait
   and the two sandbox waits.
4. **F4:** space-sky's star-counter negative control, restored now: on the standard map with the world canvas
   hidden under Phaser (`underPhaser`, a flat bright backdrop), the counter must count < `STAR_FLOOR / 4`.
5. **F5:** T23.11's Tests gain "a live match's day and night skies differ" (the retired `sky.mjs` claim).
6. **F6:** the parallax bands step 2 px (low) / 1 px (full) on slow pans (R21's nearest + snapped offsets): the
   band bakes sample **linear** at **unsnapped** offsets; look-sky Level A stays within thresholds; a slow pan's
   per-frame band displacement is measured monotone with no zero frames.
7. **F8:** a check of the no-WebGL2 fallback picture: `getContext('webgl2')` forced null, title and sandbox boot
   on the stub renderer, no page errors, the page's flat backdrop where Phaser draws nothing.
