## Deliverable

```rust
pub struct Bot { pub player: PlayerId, rng: ChaCha8Rng, /* ... */ }
impl Bot {
    pub fn new(player: PlayerId, seed: u64, index: u32, skill: f32) -> Self;
    /// Produce this tick's input. Pure w.r.t. the world: reads, never mutates.
    pub fn think(&mut self, world: &World, now: f32, dt: f32) -> Input;
    /// Item use is a command, not an input; the room applies whatever this returns.
    pub fn wants_use(&self) -> Option<u8>;
}
```

## Notes

- One `substream(seed, &format!("bot{index}"))` per bot — never a shared stream, or
  two bots with the same situation act identically.
- Target selection: nearest living player within `FOV_DAY`; if none, the nearest
  world item; if none, wander toward a random spawn point.
- Movement: walk toward the target's x. Jump when blocked (`vel.x` ~ 0 while
  pressing a direction) or when the target is more than `STEP_UP` above. Jetpack
  when the target is more than 120 px above and fuel is over half.
- Aim: exact bearing plus a gaussian-ish error of `(1 - skill) * 0.35` rad, and a
  reaction delay of `(1 - skill) * 0.4` s implemented as a lagged target position.
- Fire only when armed, in range, cooldown elapsed, and the straight line to the
  target is not blocked by more than 12 solid samples.
- Never fire when the target is within its own blast radius of the bot.
- `wants_use` returns a medkit slot below 40 health, else a shield slot when an
  enemy is within 200 px.

## Tests

- Determinism: same seed and same world produce byte-identical input sequences over
  600 ticks.
- Two bots with different indices produce different sequences.
- A bot with no target and no items still produces valid inputs and does not panic.
- A bot on flat ground with a target to its right presses `right` and not `left`.
- A bot does not fire at a target inside its own blast radius.
- A bot below 40 health with a medkit in slot 2 returns `Some(2)` from `wants_use`.
- `think` never mutates the world (enforced by `&World`).
