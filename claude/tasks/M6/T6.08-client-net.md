export class Connection {
  connect(url: string, name: string, skinId: number): Promise<Welcome>;

  on<E extends keyof ServerEvents>(e: E, cb: ServerEvents[E]): void;

}

// worldMirror.ts — the client's view of the server's world
export class WorldMirror {
  constructor(core: Core);
  applyMapInit(m: MapInit): void;
  applySnapshot(s: Snapshot): void;
  applyEvent(e: ServerEvent): void;
  readonly players: Map<number, RemotePlayerState>;
  readonly items: Map<number, WorldItemView>;
  readonly projectiles: Map<number, ProjectileView>;
  readonly pendingCarves: number;   // buffered, waiting on a missing seq

## Notes

**Carve ordering is the trap.** Carves must be applied to the local mask in `seq`
order (`docs/42-netcode-prediction.md` §6). Keep a `nextCarveSeq` counter and a small
map of out-of-order carves. Apply in order; buffer anything ahead of the counter. If
a gap persists for more than 2 s, call `requestResync()` — a missing carve means the
local terrain is permanently wrong, and everything downstream (collision,
prediction, rendering) is wrong with it.

**Never carve speculatively.** A predicted crater in the wrong place corrupts
collision for the local player and every prediction after it.

The `WorldMirror` **does not render**. It maintains state; scenes read from it. That
separation is what lets it be unit tested without Phaser.

Reconnection: socket.io reconnects automatically. On reconnect, treat it as a fresh
join — there is no session resume in v1 (`docs/40-net-protocol.md` §6). Show a
"reconnecting" overlay and **freeze remote interpolation** rather than extrapolating
indefinitely; players sliding confidently through walls is worse than frozen figures.

Malformed messages: log and ignore, never throw into the Phaser loop. One bad frame
should not kill the game.

`applySnapshot` stores snapshots into a small ring buffer for T6.10's interpolation;
it does not interpolate here.

## Tests

`client/src/net/worldMirror.test.ts`, with the connection mocked:

- `applyMapInit` loads the mask into `Core` and the hash matches the fixture.
- **Carves apply in `seq` order**: deliver seq 1, 3, 2 and assert the final mask
  equals applying 1, 2, 3 in order.
- A carve arriving with a gap is buffered and `pendingCarves` reflects it.
- The gap resolving applies the buffered carves immediately, in order.
- A gap persisting past 2 s triggers `requestResync`.
- `applySnapshot` populates `players` with the right ids and fields.
- A player absent from a snapshot is removed from `players`.
- `item_spawn` / `item_pickup` / `item_despawn` add and remove from `items`
  correctly.
- `projectile_spawn` / `projectile_despawn` likewise.
- A malformed event is logged and ignored, and the mirror stays usable.
- A duplicate `carve` seq is applied exactly once.
- The reconnect path resets the mirror and awaits a fresh `map_init`.
