## Deliverable

**Server:**
```rust
pub enum RoundPhase { Lobby, Warmup, Playing, Ended }

pub struct RoundController {
    pub phase: RoundPhase,
    pub phase_started_at: f32,
    pub round_number: u32,
    pub seed: u64,
    votes: HashMap<PlayerId, bool>,
}

impl RoundController {
    /// Advance the phase machine. Returns events to broadcast.
    pub fn tick(&mut self, world: &mut World, player_count: usize, now: f32)
        -> Vec<GameEvent>;
    pub fn vote(&mut self, id: PlayerId, restart: bool);
}
```

**Client:** a scoreboard overlay shown during `Ended` with each player's name and
score, a countdown, and **Restart** / **Quit** buttons.

## Notes

Durations: `Warmup` 10 s, `Playing` 240 s, `Ended` 20 s. During `Warmup`, players
can move but there is **no damage, no weather and no item spawns** — T6.01 gates
this; verify it holds here.

**The vote rule**: at the end of the window, a majority of *connected* players
voting restart starts a new round. **Non-voters are abstentions, not "no"** — a
player who alt-tabs should not veto the round. This is a small decision with a large
effect on how the game feels between rounds.

On restart: `next_seed = hash(current_seed, round_number)` so the sequence of maps
is itself reproducible — worth having when a run of rounds produces a bad map and
you want to get back to it. Scores reset to 0, phase → `Warmup`, and a fresh
`map_init` goes to everyone.

Score is `i16` and **may go negative** (`docs/21-player-stats.md` §6). There is no
floor at zero — a player who only dies should end below it. Do not clamp on the
client either.

Scoreboard sort: score descending, then fewest deaths, then join order. Ties at the
top are shown as ties; there is no tiebreaker round.

`round_state` is broadcast on every phase change **and once per second during
`Playing`**, so a client that missed a transition self-corrects.

If every player leaves, return to `Lobby` and drop the world.

## Tests

**Server** (`crates/game-server/tests/round.rs`, with a shortened
`ROUND_SECONDS=5`):

- Lobby → Warmup when `MIN_PLAYERS_TO_START` is reached.
- Warmup lasts exactly `WARMUP_SECONDS`, then Playing.
- Playing lasts exactly `ROUND_SECONDS`, then Ended.
- Ended lasts exactly `ENDED_SECONDS`.
- `round_state` is emitted at every transition and once a second during Playing.
- **No damage during Warmup** — fire into a player and assert unchanged health.
- No weather effect and no item spawn during Warmup.
- A majority restart vote starts a new round with a **different** seed and zeroed
  scores.
- A minority vote returns to Lobby.
- **Non-voters do not block a restart**: 3 players, 2 vote restart, 1 abstains →
  restart happens.
- All players leaving returns to Lobby.
- A vote sent outside `Ended` is ignored.
- A player voting twice counts once (the latest).
- `next_seed` is deterministic from `(seed, round_number)`.

**Client** (`scoreboard.test.ts`):
- Sorting is by score desc, then deaths asc, then join order.
- Negative scores display correctly and are not clamped.
- The countdown reflects the remaining `Ended` time.
- Clicking Restart sends `vote_restart { restart: true }`.
