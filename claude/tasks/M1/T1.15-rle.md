## Deliverable

```rust
/// Encode a mask as alternating runs, starting with a run of CLEAR pixels
/// (length 0 if the first pixel is solid). Row-major, no per-row framing.
pub fn encode(mask: &Mask) -> Vec<u8>;

/// Decode into a mask of the given dimensions. Fails rather than panics on
/// malformed input — this decodes untrusted network data.
pub fn decode(w: u32, h: u32, bytes: &[u8]) -> Result<Mask, RleError>;

pub enum RleError { Truncated, Overrun { expected: u64, got: u64 }, VarintTooLong }
```

Run lengths are LEB128 varints, in **pixels**.

## Notes

Starting with a clear run (possibly of length 0) removes the need for a per-run
flag byte — the parity of the run index tells you the value. It costs one byte in
the worst case and simplifies both sides.

**The decoder handles untrusted input.** It is reached directly from a network
message. It must never panic, never allocate based on an unvalidated length, and
never write past the mask. Specifically:
- a varint longer than 10 bytes is `VarintTooLong`;
- a run that would push the total past `w*h` is `Overrun` — do not clamp silently;
- input that ends before `w*h` pixels are produced is `Truncated`;
- trailing bytes after `w*h` pixels are reached are an error, not ignored.

Encode using whole-word scanning where possible (`trailing_zeros` / `leading_ones`
on `u64`) rather than per-pixel. A 1 MiB mask is 8 M pixels; a per-pixel loop is
noticeably slow and this runs on every round start.

Decode should use `set_run` for solid runs and skip clear runs entirely (the mask
starts empty).

## Tests

- Round-trip: `decode(w, h, encode(m)) == m` for an empty mask, a full mask, a
  single set pixel, a single clear pixel in a full mask, and 20 real generated maps
  at each scale.
- Round-trip via `proptest` over random masks built from random runs.
- **The pathological case**: alternating single pixels. Round-trips correctly, and
  the encoded size stays under `w*h/4` bytes — assert the bound so a naive
  one-byte-per-pixel encoding cannot slip in.
- Compression: a real medium-scale map encodes to under 120 KB. (The doc estimates
  20–60 KB; the assertion is deliberately loose so terrain tuning does not break
  the test, but it will still catch a broken encoder.)
- Truncated input returns `Truncated`, not a panic.
- Input claiming more pixels than `w*h` returns `Overrun`.
- An 11-byte varint returns `VarintTooLong`.
- **Fuzz**: 10 000 random byte strings of random lengths are all either decoded or
  rejected, with no panic. A panic here is a remote crash.
- Trailing garbage after a complete mask is rejected.
