## Deliverable

```rust
/// Carve `params.cave_tunnels` winding tunnels through the solid mass.
/// Returns the tunnel paths, which T1.13 uses to place buried item slots nearby.
pub fn carve_caves(mask: &mut Mask, seed: u64, params: &GenParams) -> Vec<Vec<Point>>;
```

## Notes

One tunnel:

1. **Pick a start.** Sample random points until one is solid and has solid
   neighbours within 32 px in all four directions — start inside the rock, not on
   its skin. Cap at 200 attempts; if none found, skip this tunnel.
2. **Pick a heading**, biased toward horizontal: sample the angle uniformly, then
   pull it toward 0 or π. A simple way — sample `a` in `−π..π`, then use
   `a * 0.55`, mirrored for leftward tunnels. Without this bias tunnels drill
   straight down through the bedrock and out, producing a map full of vertical
   shafts.
3. **Walk.** Each step: turn by up to `±TUNNEL_TURN_MAX` (0.35 rad), advance
   `TUNNEL_STEP` (8) px, stamp an empty circle of the tunnel's radius. Continue for
   a total length in `TUNNEL_LENGTH_MIN..=TUNNEL_LENGTH_MAX`.
4. **Vary the radius** along the tunnel between `TUNNEL_RADIUS_MIN` and
   `TUNNEL_RADIUS_MAX` by a slow random walk, so it pinches and widens instead of
   being a uniform pipe. Widen slightly is fine; changing by more than 2 px per step
   looks like a string of beads.
5. **Stop early** if the walk leaves the map bounds.

Record every stamped centre into the returned path.

Use `substream(seed, "caves")`.

Call `force_borders` at the end — a tunnel must not breach the walls or bedrock.

Reuse `stamp_circle` from T1.05 with `solid = false`.

## Tests

- Determinism: same seed produces the same mask hash, 20 times.
- `carve_caves` never increases `count_solid` (it only removes).
- With `cave_tunnels = 0` the mask is unchanged and the returned vec is empty.
- Borders still hold afterwards — specifically, no bedrock pixel was cleared.
- Every returned path has at least `TUNNEL_LENGTH_MIN / TUNNEL_STEP` points, unless
  it terminated at the map edge.
- Consecutive points in a path are `TUNNEL_STEP` apart, within a 1 px tolerance.
- The heading change between consecutive segments never exceeds `TUNNEL_TURN_MAX`.
- Tunnels are meaningfully horizontal: over 50 seeds, the mean absolute vertical
  displacement of a path is less than its horizontal displacement.
- On a fully solid mask, the carved volume is roughly the expected swept area
  (within 30 % — self-overlap on turns makes it inexact, which is why the tolerance
  is loose).
