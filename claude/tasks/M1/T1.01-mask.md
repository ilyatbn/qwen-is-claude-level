## Deliverable

```rust
#[derive(Clone, PartialEq, Eq)]
pub struct Mask {
    pub w: u32,
    pub h: u32,
    words: Vec<u64>,          // (w*h + 63) / 64, row-major
}

impl Mask {
    pub fn new_empty(w: u32, h: u32) -> Self;   // panics unless both are multiples of CHUNK_SIZE
    pub fn new_full(w: u32, h: u32) -> Self;

    #[inline] pub fn get(&self, x: i32, y: i32) -> bool;   // out of bounds → false (air)
    #[inline] pub fn set(&mut self, x: i32, y: i32);       // out of bounds → no-op
    #[inline] pub fn clear(&mut self, x: i32, y: i32);
    #[inline] pub fn put(&mut self, x: i32, y: i32, solid: bool);

    /// Set or clear an inclusive horizontal run. The workhorse for circle fill —
    /// must use whole-word writes for the interior, not a per-pixel loop.
    pub fn set_run(&mut self, y: i32, x0: i32, x1: i32);
    pub fn clear_run(&mut self, y: i32, x0: i32, x1: i32) -> u32;   // returns bits actually cleared

    pub fn count_solid(&self) -> u64;
    pub fn words(&self) -> &[u64];
    pub fn words_mut(&mut self) -> &mut [u64];
    pub fn hash(&self) -> [u8; 32];            // blake3 over w, h and the words
    pub fn chunks_x(&self) -> u32;             // w / CHUNK_SIZE
    pub fn chunks_y(&self) -> u32;
}
```

## Notes

Indexing: `bit = y as u64 * w as u64 + x as u64`, `word = bit >> 6`,
`shift = bit & 63`.

Because `w` is always a multiple of 256 and `256 % 64 == 0`, **every row starts on
a word boundary**. Rely on this in `set_run`/`clear_run` — it makes the interior a
plain `words[a..b].fill(0)` with only two masked partial words at the ends.

Out-of-bounds `get` returns `false`, meaning air. This is the right default: a
player walking past the map edge does not collide with imaginary rock (the real
wall is the `WALL_W` band of set bits). Out-of-bounds `set`/`clear` are silent
no-ops rather than panics — carve circles routinely overhang the edge.

`clear_run` returning the count of bits actually cleared is what lets T1.14
maintain the coarse grid without recounting. Use `count_ones()` on the old word
values ANDed with the write mask.

This type is on the hottest path in the project. Mark the accessors `#[inline]`,
and do not add bounds-checking beyond what is specified.

## Tests

- `new_empty` has `count_solid() == 0`; `new_full` has `count_solid() == w*h`.
- `new_empty(100, 100)` panics (not a multiple of `CHUNK_SIZE`).
- Set then get, at (0,0), (w−1,h−1), and 100 random points.
- Out-of-bounds get returns false for negative and past-edge coordinates.
- Out-of-bounds set does not panic and does not change `count_solid`.
- `set_run` across a word boundary (x0=60, x1=70) sets exactly 11 bits.
- `set_run` spanning several whole words sets exactly the right count.
- `clear_run` returns exactly the number of bits that were set before the call.
- `clear_run` on an already-clear run returns 0.
- A run with `x1 < x0` is a no-op returning 0.
- Runs clamp at row edges and never write into the neighbouring row — set a full
  row, clear a run that overhangs both ends, and assert neighbouring rows are
  untouched. (This is the classic bug in flat bitsets; test it explicitly.)
- `hash()` is stable across clones and differs after a single bit flip.
