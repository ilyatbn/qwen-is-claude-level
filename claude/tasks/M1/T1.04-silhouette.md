## Deliverable

```rust
/// Tunables for one generation attempt. The "safe preset" (T1.11) is this struct
/// with milder values, which is why the parameters live here rather than being
/// read from constants at each use site.
#[derive(Clone, Debug)]
pub struct GenParams {
    pub scale: MapScale,
    pub solid_threshold: f32,
    pub bias_top: f32,
    pub bias_bottom: f32,
    pub blob_count: u32,
    pub cave_tunnels: u32,
}
impl GenParams {
    pub fn default_for(scale: MapScale) -> Self;   // from constants
    pub fn safe_for(scale: MapScale) -> Self;      // see Notes
}

/// Pass 2. Fills a fresh mask with the thresholded, biased, warped noise field,
/// then forces the borders.
pub fn silhouette(seed: u64, params: &GenParams) -> Mask;

/// Force bedrock, side walls and the sky margin. Called after every pass that
/// can disturb them.
pub fn force_borders(mask: &mut Mask);
```

## Notes

The per-pixel rule, exactly:

```
t     = y as f32 / h as f32
bias  = lerp(bias_top, bias_bottom, smoothstep(t))
v     = warped_fbm(x * NOISE_BASE_SCALE, y * NOISE_BASE_SCALE, terrain_seed)
solid = (v + bias) > solid_threshold
```

where `terrain_seed` comes from `substream(seed, "terrain")` — take one `u64` draw
from it and pass that to the noise functions, rather than threading the RNG into
the per-pixel loop. The noise functions are pure and stateless; calling an RNG
inside a 4.7-million-iteration loop would be both slow and pointless.

`force_borders` is a separate public function because passes 3–6 all disturb the
borders and each must re-apply it. Writing it once here prevents four subtly
different copies.

`GenParams::safe_for` produces a duller but reliably connected map: threshold
lowered by 0.06 (more solid), `bias_bottom` raised to 0.55, blobs and tunnels
halved. T1.11 uses it as the last-resort fallback.

Do **not** log from this file — `game-core` is pure. Generation logging happens in
`game-server`, from the `MapMeta` this eventually produces.

Watch the cost: this is the single most expensive loop in the project. Hoist
everything invariant out of it. No allocation inside the loop.

## Tests

- Determinism: same seed and params produce an identical mask hash, 20 times.
- Different seeds produce different masks.
- After `silhouette`, borders hold: every pixel in the bottom `BEDROCK_H` rows is
  solid; every pixel within `WALL_W` of the left and right edges is solid; every
  pixel in the top `SKY_MARGIN` rows is air.
- `force_borders` is idempotent.
- Solid fraction is in a sane band (roughly 0.25–0.65) for 50 random seeds at
  medium scale. Outside that band the threshold or bias is misconfigured and every
  later pass will struggle — catch it here.
- The top row (below `SKY_MARGIN`) is far less solid than the bottom row — assert
  the bias is actually applied and in the right direction.
- Mask dimensions match the scale's params.
- `safe_for` produces a strictly higher solid fraction than `default_for` on the
  same seed.
