## Deliverable

```rust
pub struct Components {
    pub labels: Vec<u32>,        // one per pixel, 0 = unlabelled
    pub sizes: Vec<u32>,         // index = label
    pub count: u32,
}

/// Label 4-connected regions of `solid` (true) or air (false).
pub fn label(mask: &Mask, solid: bool) -> Components;

/// Pass 6. Deletes tiny solid blobs, fills tiny air pockets, and returns the
/// sealed air pockets that survived — T1.13 places buried items near them.
pub fn cleanup(mask: &mut Mask) -> Vec<SealedPocket>;

pub struct SealedPocket { pub label: u32, pub size: u32, pub centroid: Point }
```

## Notes

**Iterative flood fill with an explicit `Vec<Point>` stack. Never recursion.** A
4096×2048 map has components of millions of pixels; a recursive fill blows the
stack immediately and the crash is far from obvious.

Pre-allocate the stack once with a sensible capacity and reuse it across
components — repeatedly growing a `Vec` inside the labelling loop is where this
pass spends its time otherwise.

The **sky region** is the air component containing `(w/2, 0)`. Everything else that
is air and not connected to it is a sealed pocket.

Order of operations matters:
1. Label solid; delete components smaller than `MIN_BLOB_PX` (clear their pixels).
2. Re-label air (the deletions changed it); fill components smaller than
   `MIN_POCKET_PX`.
3. Identify the sky region; every remaining air component that is not it is a
   sealed pocket — **keep it**, and return it. These are legitimate caves, and they
   are where buried items live. Do not fill them.
4. `force_borders`.

Skipping the re-label in step 2 is the subtle bug here: deleting solid blobs merges
air regions, and stale labels then mis-classify a large cave as tiny.

`labels` is a `Vec<u32>` of `w*h` entries — 32 MB at the largest scale. That is
acceptable for a round-start operation, but it must not be retained: `cleanup`
drops it before returning. Only the pocket summaries survive.

## Tests

- `label` on an empty mask (solid) returns `count == 0`.
- `label` on a full mask returns `count == 1` with `size == w*h`.
- Two separated squares label as two components with correct sizes.
- Diagonally-touching squares label as **two** components (4-connectivity, not 8).
- A large component (over 1 M pixels) labels without stack overflow — this is the
  test that catches accidental recursion.
- `cleanup` removes a deliberately placed 100-pixel solid blob (`< MIN_BLOB_PX`) and
  keeps a 1000-pixel one.
- `cleanup` fills a deliberately placed 50-pixel air pocket and keeps a
  500-pixel one, returning the latter as a `SealedPocket`.
- A cave connected to the sky is **not** returned as sealed.
- Sealed pocket centroids are inside the pocket.
- Borders hold afterwards.
- Determinism: same input, same output and same pocket list, 20 times.
