pub struct CaveNetwork {
    pub chambers: Vec<Point>,
    pub edges: Vec<(usize, usize)>,
    pub entrances: Vec<usize>,   // indices into `chambers`
    pub paths: Vec<Vec<Point>>,  // every stamped centre, for buried-slot placement

/// Chambers + spanning tree + loop edges + surface entrances.
pub fn carve_network(mask: &mut Mask, seed: u64, params: &GenParams) -> CaveNetwork;

/// A random walk steered toward `target`: turn toward the bearing by at most
/// TUNNEL_TURN_MAX, plus jitter up to TUNNEL_TURN_MAX * 0.6.
pub fn walk_to(mask: &mut Mask, rng: &mut ChaCha8Rng, from: Point, target: Point,
               r_min: i32, r_max: i32, max_steps: usize) -> Vec<Point>;

## Notes

- `substream(seed, "chambers")`.
- Chamber placement: reject candidates without 40 px of solid in all four
  directions, min separation `CHAMBER_MIN_SEPARATION`, y in
  `SKY_MARGIN + 120 .. h - BEDROCK_H - 40`. 200 attempts each, skip on failure.
- Spanning tree: Prim's over Euclidean distance, ties broken by lower index, so it
  is deterministic without sorting floats.
- Loops: `round(chambers.len() as f32 * CAVE_EXTRA_EDGE_FRACTION)` extra edges,
  chosen shortest-first from the non-tree pairs.
- Entrances: `CAVE_ENTRANCES_MIN..=CAVE_ENTRANCES_MAX` distinct chambers, each
  walked toward `(cx + jitter, SKY_MARGIN)` at radius `ENTRANCE_RADIUS`. Stop when
  `y <= SKY_MARGIN`, or when 32 consecutive stamped px were already air.
- `force_borders` at the end.

## Tests

- Determinism: same seed, same mask hash, 20 times.
- Never increases `count_solid`.
- `edges` contains a spanning tree: a union-find over `edges` puts every chamber in
  one set.
- The number of edges is `chambers - 1 + round(chambers * CAVE_EXTRA_EDGE_FRACTION)`
  (or fewer if there are not enough distinct pairs), and there are no duplicate or
  self edges.
- `entrances.len()` is within `CAVE_ENTRANCES_MIN..=CAVE_ENTRANCES_MAX` when there
  are enough chambers.
- **Reachability, the point of the task:** on a fully solid mask, after
  `carve_network`, a flood fill of air from the sky region reaches every chamber
  centre. Assert over 20 seeds.
- Borders still hold; no bedrock pixel cleared.
- With `cave_chambers = 0` the mask is unchanged.
