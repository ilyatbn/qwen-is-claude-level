```rust
pub fn carve_voids(mask: &mut Mask, seed: u64, params: &GenParams) -> Vec<Point>;
```

## Notes

- Sub-streams `"crevices"` and `"voids"`.
- A crevice starts at the **first solid pixel** in a random column; if that column
  has no solid pixel above `h - BEDROCK_H`, skip it (do not loop forever — 200
  attempts total).
- Heading starts straight down and wanders by up to `CREVICE_WANDER` per step.
  Radius is `width / 2` tapering linearly to 60 % of that at the bottom.
- Voids: cluster of 3–6 empty circles, min centre separation `VOID_MIN_SEPARATION`,
  50 placement attempts each.
- `force_borders` after each function.

## Tests

- Determinism for both, 20 times.
- Neither increases `count_solid`.
- Zero counts leave the mask unchanged.
- A crevice's first stamped point is air-above-solid before carving (it started at
  the surface).
- Crevice depth is within `CREVICE_DEPTH_MIN..=CREVICE_DEPTH_MAX`, and no stamped
  point is below `h - BEDROCK_H`.
- Consecutive crevice points are `CREVICE_STEP` apart (±1) and the heading never
  turns by more than `CREVICE_WANDER`.
- Void centres respect `VOID_MIN_SEPARATION`.
- Borders hold after both.
