## Deliverable

```rust
pub struct CoarseGrid {
    pub cw: u32,          // cells across = w / COARSE_CELL
    pub ch: u32,
    counts: Vec<u8>,      // solid pixels per 8×8 cell, 0..=64
}

pub enum CellState { Empty, Full, Mixed }

impl CoarseGrid {
    /// Full recount from a mask. O(w*h) — round start and tests only.
    pub fn build(mask: &Mask) -> Self;

    #[inline] pub fn cell_at(&self, x: i32, y: i32) -> CellState;      // world pixels
    #[inline] pub fn count_at(&self, cx: u32, cy: u32) -> u8;

    /// Subtract `n` from a cell's count. Used by carve. Saturating.
    #[inline] pub fn subtract(&mut self, cx: u32, cy: u32, n: u8);
    #[inline] pub fn add(&mut self, cx: u32, cy: u32, n: u8);

    /// Debug-only: verify every cell against a from-scratch recount.
    pub fn verify(&self, mask: &Mask) -> Result<(), (u32, u32, u8, u8)>;
}
```

## Notes

The whole value of this structure is answering "can I skip this cell?" without
touching bits. `Empty` and `Full` are decisive; only `Mixed` requires per-pixel
work. On typical generated terrain most cells are one of the two extremes, which
is why collision (T2.02) rarely reads the mask at all.

`subtract` saturates rather than wrapping. An underflow means the count and the
mask have diverged — a real bug — but wrapping to 255 would turn a small
bookkeeping error into "this empty cell is now completely solid", which is far
harder to trace. In debug builds, `debug_assert!` on underflow so it is loud.

`verify` returns the first mismatching cell with both counts rather than a bare
bool. When it fires in a test you want to know *where*, immediately.

Out-of-bounds `cell_at` returns `Empty`, consistent with `Mask::get` returning air.

## Tests

- `build` on an empty mask: every cell `Empty`, every count 0.
- `build` on a full mask: every cell `Full`, every count 64.
- A mask with one solid pixel: exactly one cell is `Mixed` with count 1, and it is
  the correct cell.
- A mask with one fully solid 8×8 cell reports `Full` for it and `Empty` around it.
- `cell_at` maps world pixel (0,0) and (7,7) to cell (0,0), and (8,0) to cell (1,0).
- Out-of-bounds `cell_at` returns `Empty` for negative and past-edge coordinates.
- `subtract` past zero saturates at 0 rather than wrapping.
- `verify` returns `Ok` for a freshly built grid.
- `verify` returns `Err` with the right cell after manually corrupting one count.
- Grid dimensions are correct for all three map scales.
