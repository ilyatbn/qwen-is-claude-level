# T16.02 — Stamp objects into the map (v5)

Milestone: M16 · Depends on: T16.01 · Size: ~220 lines

## Read first
- `docs/73-amendments-v5.md` §D1, §D3, §D5
- `docs/10-map-generation.md` §7 (the validation this must run before)

## Deliverable

A generation pass, **6b — objects**, between cleanup and validation:

```
… 5 smoothing → 6 cleanup → 6b OBJECTS → 7 validation → 8 metadata
```

Place `OBJECT_COUNT` objects (18/30/48 by scale) on surface points from
`substream(seed, "objects")`, respecting `OBJECT_MIN_SEPARATION` (64),
`OBJECT_CLEAR_OF_SPAWN` (96) and `OBJECT_PIXEL_BUDGET` (0.02 of map area), and
**stamp each one's bitmask into the terrain mask as solid**.

From that moment the object *is* terrain: destructible, collidable, carved by the
same bit-exact `carve_circle`, with no new entity, no new damage path and nothing on
the wire (§D1, §D8).

## Notes

- **The pass position is load-bearing and §D3 explains each neighbour.** After
  smoothing or the CA erodes thin branches; after cleanup or `MIN_BLOB_PX` deletes
  small crystals; before validation or an object sealing a cave mouth is never
  caught; before metadata or **items spawn inside trees and players inside rocks**.
- Anchor to the ground the way decorations already do (`docs/50` §6) — walk from the
  anchor until the base is supported.
- Rejection sampling, capped, then stop. Never loop forever (`docs/32` §2).
- The budget is measured in **pixels added**, not object count, because a ruin is
  worth twenty bushes.
- This changes generated masks: **regenerate the golden table and re-run the
  999-seed sweep**, reporting the new attempt distribution and safe-preset rate, as
  T9.04 and T15.02 do. If traversability degrades, that is a finding, not a threshold
  to lower.

## Tests

- Determinism: same seed → identical mask hash, 20 times.
- Sub-stream isolation: draining the `"items"` stream does not move an object.
- No object overlaps a spawn point or teleport pad within `OBJECT_CLEAR_OF_SPAWN`.
- Centres respect `OBJECT_MIN_SEPARATION`; the pixel budget is never exceeded.
- **Surface points extracted afterwards include object tops** — you can stand on a
  rock. This is the assertion that proves the ordering.
- A carve over an object removes its pixels like any terrain.
- Borders still hold; bedrock and walls untouched.
- The 999-seed sweep passes with its numbers reported.
