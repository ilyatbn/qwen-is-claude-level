# T16.01 — PNG to terrain mask: the build pipeline (v5)

Milestone: M16 · Depends on: T7.02 · Size: ~250 lines

## Read first
- `docs/73-amendments-v5.md` §D0, §D2, §D4
- each pack's `CATALOGUE.md` (generated by `scripts/catalogue-sprites.mjs`)

## Deliverable

`scripts/build-object-masks.mjs`: read the selected PNGs, threshold alpha at
`OBJECT_ALPHA_THRESHOLD` (128), trim to the opaque bounding box, scale
**nearest-neighbour** by the category factor derived from §D4's target height, and
emit:

- `assets/objects/masks.bin` — packed 1-bit masks, row-major, one blob
- `assets/objects/manifest.json` — id, key, pack, category, w, h, anchor, blob offset
- `assets/atlas/objects.png` + `.json` — the art

`game-core` embeds `masks.bin` with `include_bytes!` so the crate stays pure — no
`std::fs` (`CLAUDE.md`).

## Notes

- **Ruins is 40 objects, not 164** (§D0): `Assets`, `Assets_shadow`,
  `Assets_texture_shadow` and `Assets_texture_shadow_dark` have identical basenames
  and are render variants. Pick one set.
- **Clouds are excluded** — they go to the sky layer (T16.04), not the terrain.
- Scale is derived from **each sprite's own measured bounds**, not applied blindly
  from the pack mean, or a small crystal and a large one end up the same size.
- Horizontal flip is exact on a bitmask and doubles variety; store it as a flag, do
  not bake two masks.
- Emit the id → key mapping such that **array position equals id**, and assert it —
  §B16: both registries silently assumed this and a laser resolved as a bazooka.

## Tests

- A hand-built 8×8 PNG with a known alpha pattern produces exactly the expected bits.
- Trimming: a sprite with 40 px of empty margin yields bounds without it.
- Nearest-neighbour scaling at an integer factor is exact and reversible.
- Every manifest entry's `w × h` matches its blob length in bits.
- Ids are contiguous and match array position (falsify by inserting at the front).
- The whole pack set round-trips: every selected PNG produces a mask with a non-zero
  bit count, and the test **names** any that do not.

## Done when

```sh
node scripts/build-object-masks.mjs --check && npm --prefix client test -- --run objectMasks
```
