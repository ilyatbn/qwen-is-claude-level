## Deliverable

One extra step in the chunk bake, between the fill and the punch-out:

```
1  alpha stencil from the mask slice        (unchanged)
2  tiling rock fill                          (unchanged)
2b objects overlapping this chunk            ← new
3  destination-in with the stencil           (unchanged — clips 2 and 2b)
4  edge band                                 (unchanged)
```

**Destruction needs no per-object work at all**: the art is clipped by the live mask,
so blowing half a tree away removes half the tree's art (§D1).

## Notes

- Build a chunk → objects index once at map load; do not search every bake.
- An object spanning a chunk boundary draws in both, offset — the same margin logic
  the edge band already uses for seams (`docs/12` §2).
- Missing atlas → placeholder, logged once (`docs/50` §8). The game must still start
  with no art.
- Respect the rebake budget: objects must not make a single rebake exceed 4 ms
  (`docs/60` §6).

## Tests

- **Pixel acceptance** (§C2, T13.02): a chunk containing an object renders pixels
  the object's sprite has and the rock fill does not, with a control chunk that has
  no object.
- **The payoff, asserted**: carve half an object away, and the sprite's pixels in the
  carved half are gone while the other half remains. Falsify by removing the
  `destination-in` and the carved half stays visible.
- An object on a chunk boundary is not clipped at the seam.
- Single-chunk rebake stays under 4 ms with the densest object placement the budget
  allows.
