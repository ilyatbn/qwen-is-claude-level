# T16.05 — Record where the art came from (v5)

Milestone: M16 · Depends on: nothing · Size: small, and it gates the art commit

## Read first
- `docs/73-amendments-v5.md` §D7
- `docs/51-assets.md` §8 (licensing hygiene)

## Why

`docs/51` §8 is unambiguous: *"Only CC0 or explicitly-public-domain art enters this
repo"* and *"every vendored pack keeps its `LICENSE.txt` alongside its files"*.

**`sprite_packs/` contains no licence, readme or credit file of any kind.** Its
provenance is unknown to the repository.

## Deliverable

For each pack that gets committed under `assets/`: its name, source URL, licence and
fetch date recorded in `assets/vendor/README.md`, and the pack's own licence file
alongside it — the same treatment the Kenney packs already get.

## Notes

- This gates **committing the art**, nothing else. T16.01–T16.03 can be built and
  tested against the procedural fallbacks (`docs/50` §8, `docs/51` §5), which is what
  the fallbacks are for and what carried this project from M3 to M7.
- If a pack's licence turns out to disallow redistribution, the pipeline still works —
  point it at CC0 replacements. The feature is the pipeline, not these specific
  40 rocks.
- `assets/vendor/` is gitignored (§A29); the built masks and atlas are what ship, so
  record provenance for the **source**, and note in the manifest which pack each
  object derives from.

## Tests

- A check in `verify-assets.mjs`: every pack directory referenced by
  `assets/objects/manifest.json` has an entry in `assets/vendor/README.md`, and the
  test names any that do not.
- Falsify by removing an entry.

## Done when

```sh
node scripts/verify-assets.mjs
```
