## Deliverable

Map size (small / medium / large), then **Create private** (shows the join code
prominently, with a copy button), **Join private** (enter a code), or **Quick
match** (shows waiting count and ETA from `room_list`).

A lobby screen shows who is in the room, the map size, the join code if private,
and starts when the room's phase leaves `Lobby`.

## Notes

- `Esc` always goes back one step, from anywhere.
- Every control is keyboard reachable; the code entry accepts lower case and
  normalises it, and rejects ambiguous characters with a message rather than
  silently failing.
- A failed join (`join_error`) must say **why** — full, unknown code, room gone —
  and return you to the menu with the code still in the box.
- Persist the last map size in `localStorage`.

## Tests (vitest on the pure half, Playwright on the flow)

- Code normalisation: lower case accepted, `O`/`0` and `I`/`1` rejected with a
  message.
- The state machine reaches Lobby → Game and back to Menu on `Esc` at each step.
- `join_error` renders the reason and preserves the entered code.
- Headless: two browser contexts, one creates a private room and the other joins by
  the code shown on screen — read the code **from the DOM**, not from the socket, so
  the test proves what the player can actually see.
