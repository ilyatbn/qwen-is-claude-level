## Deliverable

`scripts/check.sh` — `set -euo pipefail`, runs from the project root regardless of
where it is invoked from, and executes in order:

```sh
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --workspace
npm --prefix client run typecheck
npm --prefix client test -- --run
node scripts/verify-assets.mjs
```

Each step prints a clear banner before it runs, so a failure is immediately
attributable. Exit non-zero on the first failure.

Support `--fast` to skip `clippy` and the asset check, for the tight edit loop.

`scripts/verify-assets.mjs` — validates that every path referenced in
`assets/manifest.json` exists on disk, and that every atlas frame referenced by
`assets/skins.json` exists in that atlas's JSON. Both files are absent until M7, so
**a missing file is a skip, not a failure** — print "skipped (no manifest yet)" and
exit 0.

## Notes

`-D warnings` on clippy is deliberate and should not be softened. On a project
built one small task at a time, warnings pile up invisibly until nobody reads the
output at all.

The asset verifier is written now, before there are assets, so that it is simply
already there when M7 lands rather than being remembered at the end.

Make the script executable (`chmod +x`) and note in your report that you did.

## Tests

- `./scripts/check.sh` exits 0 on the current tree.
- Introduce a deliberate formatting error, confirm the script fails at the `fmt`
  step with a clear banner, then revert it.
- `./scripts/check.sh --fast` skips clippy and the asset check.
- `node scripts/verify-assets.mjs` exits 0 and reports "skipped" with no
  `assets/` directory present.
