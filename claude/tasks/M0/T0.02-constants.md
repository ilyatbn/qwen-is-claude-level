## Notes

Choose types deliberately: pixel dimensions are `u32`, physics values are `f32`,
counts are `u32` or `u8`, durations are `f32` seconds. Do not make everything
`f32` — the map code indexes with integers and casting everywhere invites
off-by-one bugs.

Ranges in the doc written as `a..=b` (e.g. `METEOR_FRAG_SPEED` 320..=520) become
two constants, `_MIN` and `_MAX`.

Group with section comments matching the doc's headings, so a reader can diff the
two files by eye. That diffability is the entire point of this file.

## Tests

In-file `#[cfg(test)]`, sanity relationships only — not a re-transcription:

- `SIM_DT * SIM_HZ as f32` ≈ 1.0
- `SIM_HZ % SNAPSHOT_HZ == 0` (snapshots land on whole ticks)
- Every map size is a multiple of `CHUNK_SIZE`, at every scale
- `JETPACK_MAX_FUEL * JETPACK_DRAIN / JETPACK_REFILL == 10.0` (the brief's 2:1 rule)
- `HEALTH_CAP > BASE_HEALTH`
- `EFFECT_INTERVAL_MIN < EFFECT_INTERVAL_MAX`
- `MIN_TRAVERSABLE_FRACTION` is in `(0.0, 1.0]`
