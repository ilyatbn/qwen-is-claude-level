## Deliverable

```rust
pub use rand_chacha::ChaCha8Rng;

/// FNV-1a 64-bit hash of a string. Used to derive sub-stream seeds.
pub const fn fnv1a64(s: &str) -> u64;

/// An RNG for one subsystem, isolated from all others.
pub fn substream(seed: u64, tag: &str) -> ChaCha8Rng;

/// Derive the next round's seed from this one, reproducibly.
pub fn next_round_seed(seed: u64, round: u32) -> u64;

// Small helpers used everywhere downstream:
pub fn range_u32(rng: &mut ChaCha8Rng, lo: u32, hi: u32) -> u32;   // inclusive
pub fn range_f32(rng: &mut ChaCha8Rng, lo: f32, hi: f32) -> f32;
pub fn chance(rng: &mut ChaCha8Rng, p: f32) -> bool;
pub fn pick_weighted(rng: &mut ChaCha8Rng, weights: &[u16]) -> usize;
```

Tags used across the project: `"terrain"`, `"blobs"`, `"caves"`, `"spawns"`,
`"buried"`, `"items"`, `"weather"`, `"decor"`, `"theme"`, `"wind"`. Document them
in a doc comment on `substream`.

## Notes

**`ChaCha8Rng` only.** Never `StdRng` (not stable across `rand` versions) and never
`thread_rng` (not reproducible at all). If any later task reaches for either, that
is a bug — the whole replay and golden-hash system depends on this.

`fnv1a64` is `const fn` so tags can be hashed at compile time where useful.

`pick_weighted` returns an index; a zero weight must never be selected, and an
all-zero slice should return 0 rather than panic (log-free fallback — `game-core`
does no logging).

## Tests

- Same `(seed, tag)` produces the same first 100 draws, twice.
- Different tags from the same seed produce different sequences.
- **Isolation**: drawing 10 000 values from `substream(s, "items")` does not change
  what `substream(s, "terrain")` produces. This is the property the whole design
  rests on.
- `fnv1a64` matches known FNV-1a vectors (`""` → `0xcbf29ce484222325`,
  `"a"` → `0xaf63dc4c8601ec8c`).
- `range_u32(rng, 5, 5)` always returns 5.
- `range_u32` covers both endpoints over many samples.
- `pick_weighted` never returns an index with weight 0, over 10 000 samples.
- `pick_weighted` distribution is within 2 % of expected over 100 000 samples.
- `next_round_seed` is deterministic and differs from its input.
