  addTracer(x0:number,y0:number,x1:number,y1:number): void
  addProjectile(id:number, kind:'bazooka'|'grenade'|'meteor'|'fragment'): void

## Notes

**Module split is mandatory — see `docs/70-amendments-v2.md` §A8.** Phaser cannot be
imported under vitest (node: `window is not defined`; jsdom: null 2d context). Pure
functions go in the `-math`/`-state` file; the Phaser class imports that file and is
never imported by a test.

- A tracer is a line that fades over `TRACER_LIFETIME` (0.09 s). Pool the graphics
  objects; a 10 shots/s SMG must not allocate.
- A projectile keeps the last `PROJECTILE_TRAIL_LEN` positions and draws them as a
  tapering polyline. `moveProjectile` is called from the sim each frame.
- `lights()` returns every live projectile and impact as a light source so the
  lightmap (T3.10) can erase around them — this is what makes night combat visible.
- Impacts spawn a flash, a dust puff and a short-lived scorch decal.

## Tests (vitest, on the pure bookkeeping — no Phaser calls)

- Tracers expire exactly at `TRACER_LIFETIME` and are removed from the pool.
- Trail buffers never exceed `PROJECTILE_TRAIL_LEN`.
- `removeProjectile` on an unknown id is a no-op.
- `lights()` includes every live projectile and no expired impact.
