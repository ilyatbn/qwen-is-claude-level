# T18.03 — Clouds are bigger and vary in brightness (v6)

Milestone: M18 · Depends on: nothing · Size: ~150 lines

## Read first
- `docs/74-amendments-v6.md` §E11
- `docs/72-amendments-v4.md` §C14 (cloud tint by sky phase)

## Deliverable

- **Fix the size bug first**: `parallax.ts` sets a display size and then calls `setScale`
  on the same sprite, which overrides it — so a cloud is its native frame scaled, not
  `CLOUD_TEX_W × CLOUD_TEX_H` scaled, while the wrap-twin seam maths still assumes the
  latter.
- `CLOUD_SCALE_MIN` / `MAX` up about 30%.
- **Per-cloud brightness and alpha**, seeded from the map seed, within a band — some
  darker, some lighter.
- `CLOUD_SKY_MIX` and `CLOUD_ALPHA_FLOOR` are dead on the atlas path. Give them a caller
  or delete them.

## Notes

- The size change means nothing until the override is fixed — do that first and measure
  the before/after, or you will be tuning a constant that is not being read.
- Per-cloud brightness must not undo §C14's phase response: the colour set still follows
  the sky phase, and brightness varies **within** it.
- Seeded per cloud from the map seed, so the same map always has the same sky.

## Tests

- The drawn width of a cloud matches `CLOUD_TEX_W × scale` — falsify by restoring the
  `setScale` override and watching it go red.
- The wrap twin has no seam: sample across the wrap boundary.
- Twelve clouds do not all share one brightness — assert the spread, with a control that
  they are all in the band.
- Same seed, same brightnesses, twice.
- Night clouds still differ from noon (§C14 unbroken), sampled pixels with a control.
