# T18.02 — Bots that explore, arm themselves and run (v6)

Milestone: M18 · Depends on: nothing · Size: ~250 lines

## Deliverable

Four changes to `Bot::think` / `choose_goal`:

- **Explore** — no target means moving toward unvisited parts of the map, on a coarse
  per-bot coverage grid (`BOT_EXPLORE_CELL`), not a random spawn point.
- **Arm first** — acquiring a weapon outranks chasing when poorly armed.
- **Retreat** — below `BOT_FLEE_HEALTH`, break contact and prefer distance.
- **Reachability** — item choice gets the line-of-sight test enemy choice already has.

## Notes

- `Wander`'s own comment already calls the branch near-dead; this replaces it.
- **`game-core` is pure**: seeded `ChaCha8Rng` only, no wall clock, no `thread_rng`. A
  coverage grid is per-bot state, not global.
- This is not pathfinding. A grid of visited cells and a direction is the whole model;
  say so in the doc comment so the next person does not "improve" it into A*.
- Retreat must not deadlock against `stand_off`: a bot that flees and immediately
  re-engages at range is worse than one that never fled.
- Bots run inside the attract screen no longer (T18.01), so the only consumer is a real
  match — check the production callers.

## Tests

- **Exploration covers more map than today**: run N bots for a fixed sim time on a fixed
  seed and compare visited-cell counts against the current behaviour. A metric with no
  control is a number — keep the old number in the test.
- A bot below `BOT_FLEE_HEALTH` increases its distance from the nearest enemy. Control: a
  healthy bot in the same position closes.
- An unarmed bot with a weapon and an enemy both in range goes for the weapon.
- An item behind a wall is not chosen; the same item with line of sight is.
- Determinism: same seed, same bot decisions, twenty times.
