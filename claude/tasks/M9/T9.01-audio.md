# T9.01 — Audio (v2)

Milestone: M9 · Depends on: T7.01 · Size: 2–3 files, ~250 lines

## Read first
- `docs/51-assets.md` §6 (`manifest.audio` is already the right shape), §10
- `docs/50-sprites-skins.md` §8 (missing-asset behaviour)

## Why

The builder who has played this game most named audio as "the largest single gap
in feel", and it is a game about explosions. `manifest.json` has carried an empty
`audio` array since M0 precisely so this would be additive.

## Touch only
- `client/src/audio/mixer.ts` + `mixer.test.ts` (pure — no Web Audio in the tested half)
- `client/src/audio/sfx.ts` (the Web Audio / Phaser side)
- `assets/manifest.json`, `scripts/fetch-assets.sh` (add the audio packs)
- the scenes, to fire cues

## Deliverable

```ts
export type Cue = 'fire_bazooka'|'fire_smg'|'fire_grenade'|'explode'|'hit'|'death'
  |'pickup'|'crate_land'|'jetpack'|'walk'|'land'|'ui_click'|'phase_change'
  |'effect_telegraph'|'meteor'|'lava'|'toxic'
export class Mixer {
  play(cue: Cue, opts?: { pan?: number; volume?: number; rate?: number }): void
  setMasterVolume(v: number): void
  /** Distance-attenuated, panned by screen offset. Returns the applied gain. */
  spatial(cue: Cue, worldX: number, worldY: number, listener: {x:number;y:number}): number
}
```

## Notes

- **CC0 audio from Kenney**, fetched by the same script and the same §A29 rule
  (the URL is on the `id='donate-text'` anchor, single-quoted attributes). Verified
  reachable: `impact-sounds`, `interface-sounds`, `sci-fi-sounds`, `digital-audio`.
- **The game must still run with no audio at all** (`docs/50` §8). A missing cue
  logs once and is silent — never throws, never blocks the frame.
- Browsers block audio until a user gesture. Resume the context on first input and
  do not spam the console before then.
- **Attenuate and pan spatially**: a rocket landing off-screen should be quieter
  and to one side. `FOV_DAY` is a reasonable falloff scale. Cap concurrent voices
  per cue so a meteor shower does not produce forty simultaneous impacts.
- Cue on events already broadcast (`explosion`, `death`, `item_pickup`,
  `effect_start`, `phase_change`), not on new state — the events exist.

## Tests (vitest, on `mixer.ts`, no Web Audio)

- `spatial` gain falls monotonically with distance and is 0 beyond the cutoff.
- Pan is −1 hard left, +1 hard right, 0 at the listener, and clamped.
- The per-cue voice cap drops the oldest, and never exceeds the cap.
- An unknown cue is a silent no-op and logs exactly once.
- Master volume scales every voice and clamps to `[0, 1]`.
