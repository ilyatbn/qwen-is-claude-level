# T17.04 — Private lobbies: a code, settings and ready (v6)

Milestone: M17 · Depends on: T17.02 · Size: ~200 lines

## Read first
- `docs/74-amendments-v6.md` §E3, §E5, §E6

## Deliverable

Hosting mints a code and opens an empty private lobby. Joining takes a code. The match
starts when **every seated human is ready** and there is at least one.

- No timeout, ever.
- Ready is a toggle, and **clears for everyone when the settings change**.
- The host owns settings (map size only). When the host leaves, ownership passes to the
  longest-seated remaining human; the lobby and the code survive.
- Bots are opt-in via `start_with_bots`.

## Notes

- A lobby dies when it is empty and for no other reason (§E5). Do not close it because
  the host left.
- **Ready clearing on a settings change is the point** — a player agreed to the game they
  were shown. A ready flag that survives a map-size change is consent to something else.
- Code minting, alphabet and length are unchanged (`JOIN_CODE_LEN`, `JOIN_CODE_ALPHABET`).
- `settings_owner` is a seat id on the wire, so a client can grey the stepper for
  everyone else without a second concept.

## Tests

- Two players, one ready — no start. Both ready — start. That pair is the assertion; the
  first half alone is satisfied by a lobby that never starts.
- A settings change clears every ready flag, including the changer's.
- The host leaves: the lobby survives, the code still works, and `settings_owner` moves
  to the longest-seated remaining human.
- The last human leaves: the lobby is reaped.
- A non-owner's `set_scale` is refused and changes nothing.
- A private lobby is never returned by quick match.

## A note on the Done-when

`cargo test -p game-server --lib <pattern>` **matches zero tests and exits 0** when the
pattern names nothing, and `crates/game-server/tests/` is where the lobby tests already
live — `--lib` never runs an integration target. Five of these six Done-whens were
written in that vacuous form and are corrected here to name a `--test` target. **Create
that target.** If your Done-when passes before you have written anything, it is not a
Done-when; say so rather than reporting it green.
