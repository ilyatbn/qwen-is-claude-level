## Deliverable

`lobby_state`, server→client, sent to every seated socket whenever the lobby changes —
a player joins or leaves, someone readies, settings change, or the bot timeout ticks a
whole second.

Fields per §E6: `code?`, `private`, `capacity`, `scale`, `settings_owner?`, `starts_in?`,
`players[] = { seat, name, skin_id, ready, bot }`.

Client→server: `ready { on }` (existing verb, meaning tightened) and `set_scale { scale }`
(new, refused unless the sender is `settings_owner`).

**`room_list` is deleted.**

## Notes

- **`room_list` has never had a subscriber** — `MenuScene.roomInfo` is never assigned and
  `describeRoom` has no production caller. Deleting it is the point, not a side effect;
  `docs/71` §B14 found `room_created` in exactly this state.
- Rate: `starts_in` changes 60×/s and must not be sent 60×/s. Emit on a whole-second
  change, the way `round.rs` already throttles `RoundState`.
- The client half is pure and testable without Phaser — put the decode and the reducer
  where `client/src/net/lobby.ts` already lives.
- `set_scale` from a non-owner is refused with an error, not silently ignored.

## Tests

- Every field round-trips, decoded from raw bytes/JSON, not from the encoder's own view.
- A join, a leave, a ready and a scale change each produce exactly one `lobby_state`, and
  a falsification: break the emit and the test goes red at the live site.
- `starts_in` is emitted once per whole second, not per tick — assert the count over a
  simulated 10 s, with a control that it was emitted at all.
- `set_scale` from a non-owner changes nothing and returns an error.
- `grep` proves no `room_list` producer or consumer survives.

## A note on the Done-when

`cargo test -p game-server --lib <pattern>` **matches zero tests and exits 0** when the
pattern names nothing, and `crates/game-server/tests/` is where the lobby tests already
live — `--lib` never runs an integration target. Five of these six Done-whens were
written in that vacuous form and are corrected here to name a `--test` target. **Create
that target.** If your Done-when passes before you have written anything, it is not a
Done-when; say so rather than reporting it green.

## Done when

cargo test -p game-server --test lobby_state && npm --prefix client test -- --run lobby
