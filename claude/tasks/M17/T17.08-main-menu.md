# T17.08 — SHRED, and a menu that steps (v6)

Milestone: M17 · Depends on: T17.07 · Size: ~200 lines

## Read first
- `docs/74-amendments-v6.md` §E7
- `docs/50-sprites-skins.md` §8 (missing-asset fallback), `docs/51-assets.md` §8 (licence)

## Deliverable

- The title reads **SHRED**, in a display face chosen for it rather than the body font.
- The tagline is removed.
- **Quick Game** → a public lobby, no options.
- **Private Game** → Host or Join. Host opens a lobby and shows the code; Join asks for
  one.
- **Map size is a stepper**: `‹ SMALL ›`, wrapping through `MapScale::ALL`, starting at
  Small. Built as the first row of a settings list, not as a one-off control.

## Notes

- **The font is an asset and `docs/51` §8 applies**: CC0 or explicitly public domain,
  recorded in `assets/vendor/README.md` with source, licence and fetch date, and the
  provenance check from T16.05 will fail the gate if it is not. Do not embed a font
  whose licence you cannot name.
- Missing font → the body face, logged once (`docs/50` §8). The menu must render with no
  art.
- Quick match randomises settings, so the stepper is not shown for it — do not build a
  control that silently does nothing.
- Keyboard: the stepper works with left/right arrows, and Esc still goes back one step
  (`docs/71` §B3).

## Tests

- **Pixel acceptance**: the title renders in the display face, not the body font —
  sampled pixels, with a control region of body text in the same frame.
- The stepper cycles Small → Medium → Large → Small in both directions, and the chosen
  scale is what reaches the lobby.
- Missing font falls back and logs once, not per frame.
- The provenance check passes with the font's row present, and fails with it removed.
- `grep` proves no three-button scale fieldset survives.

## Done when

```sh
npm --prefix client test -- --run menu && node scripts/verify-assets.mjs && node scripts/e2e.mjs title
```
