# T19.02 — You can see a bullet, without freezing the game (v7)

Milestone: M19 · Depends on: T19.01 · Size: ~200 lines

## Read first
- `docs/75-amendments-v7.md` §F2
- `client/src/render/ordnance-state.ts` (`LOOK`, `WEAPON_KEYS`, `KIND_BY_WEAPON_KEY`)
- `client/src/render/ordnance.ts`
- `scripts/checks/ordnance-visible.mjs` — read what it does to photograph a tracer

## Deliverable

- A `bullet` `ProjectileKind`, mapped from all five gun keys, drawn as a **streak along
  the velocity** — `BULLET_LENGTH` × `BULLET_WIDTH` — not a dot. The draw needs a
  direction, and `TrackedProjectile` currently stores positions only: derive it from the
  last two trail points rather than adding a field the server has to send.
- `TRACER_LIFETIME` → `BEAM_LIFETIME` 0.35 s. That path now serves lasers only.
- **A new e2e check, `bullets-visible`**, standalone, on a real server: fire an SMG, then
  sample the same screen patch at two instants **without calling `freeze`**, and prove
  the streak moved.

## Notes

- The old check freezes the frame before photographing. That is not a flaw in the check
  — it is the measurement that proves the old design was invisible, and it is why it
  passed for three milestones against a player who could see nothing. Say so in the new
  check's header.
- `ordnance-visible` keeps its beam half; point it at a laser weapon, which is the only
  thing that path still draws.
- Ten bullets on one line is the target picture (the M19 reference image). If the streaks
  merge into a bar at `MACHINEGUN_COOLDOWN`, that is a finding — report the measured
  spacing rather than shortening `BULLET_LENGTH` on sight.
- `WEAPON_KEYS` is pinned to the Rust registry by an existing test. Do not edit it here;
  T19.05 is the task that changes the table.
- **Assert on rendered pixels** (`CLAUDE.md`), with a control region and a control frame.

## Tests

- Unit: a bullet's streak endpoints follow its velocity direction; a stationary bullet
  (no second trail point yet) draws a dot rather than a NaN.
- Unit: `KIND_BY_WEAPON_KEY` maps all five gun keys to `bullet` and neither laser to it.
- Unit: a beam lives `BEAM_LIFETIME`, pinned to the constant.
- e2e `bullets-visible`: patch differs from the control frame while a bullet is crossing
  it; two samples ~120 ms apart put the streak at **different** x; and a control patch
  the shot never crosses does not change.
- e2e: the same check with the shot fired away from the patch changes nothing — the
  control that stops it passing on a bright muzzle flash.
