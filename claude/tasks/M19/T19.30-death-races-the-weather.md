# T19.30 — `death`'s kill races the weather's (v7)

Milestone: M19 · Depends on: nothing · Size: small

**Found in suite 2 of T19.23's five-suite verification.** Passed suites 1, 3 and 4; failed
suite 2:

```
cause reads "Killed by weather", expected the self-kill wording
```

A **weather tick landed the killing blow first**. The check sets the player's health to 1 and
then kills them, and between those two acts a hazard can get there — so the overlay names the
weather, correctly, and the assertion about the self-kill wording fails.

## Sixth in the family, and a different sub-shape

Five members are a sampler arriving before the thing it photographs — `bullets-visible`,
`teleport`, `rematch` ×2, `night-combat`, `reap`. **This one is not that.** Nothing is being
sampled too early: the *setup* opens a window in which an unrelated system can satisfy the
precondition first.

So the remedy is different too. The others were fixed by waiting on the condition the next line
asserts. **Here there is nothing to wait for — the race is in the arrangement, not the
observation.** Options, and say which:

- **Close the window**: kill the player without the health-to-1 step, or in one act, so no tick
  falls between them.
- **Remove the competitor**: run the check with weather off, if the claim under test is about
  the self-kill wording rather than about hazards.
- **Assert the disjunction honestly**: if a weather death is a legitimate outcome of this
  arrangement, the check should say which death it got and only fail on a *third* thing. This
  is the weakest option and needs an argument, because it would stop the check noticing a
  self-kill that silently stopped working.

The first is almost certainly right. **Do not pick the third to make the red go away.**

## Watch for

- **The self-kill claim must survive.** `death`'s job is that a self-inflicted death reports
  the right cause; a fix that passes whichever way the player died has retired it.
- Setting health to 1 may be load-bearing for a *different* assertion in the same check. Read
  the whole file before removing it — `CLAUDE.md`: *share the guard, or share the function*,
  and here the guard may be shared with a claim nobody is thinking about.

## Tests

- Passes 5 consecutive times **inside a full suite**. Standalone is where it already passes.
- **Falsify**: break the self-kill cause attribution and the check must still go red. A fix
  that made the arrangement robust by asserting less would pass this only if the assertion is
  still there to fail.
