## Deliverable

Three settings on a private lobby, alongside map size and behaving exactly like it:

| Setting | Values | Default |
|---|---|---|
| `bots` | on / off | on |
| `start_kit` | `none` / `basic` / `all` | `none` |
| `round_seconds` | `ROUND_SECONDS_MIN`..`MAX` step `ROUND_SECONDS_STEP` | `MIN` |

- Host-only, changeable any time before the start, **and every change clears every ready
  flag** — the same path `SetScale` takes.
- **Recorded in the replay**, for the reason `SetScale` is: a setting that changes what
  is built and is not recorded makes the replay a different match (§E1.2).
- Carried in `lobby_state` so every seat sees the current settings, not just the host.
- Honoured at match start: no bots at all when off; the kit granted to every player on
  spawn **and respawn**; the round clock started at the chosen length.
- `none` is the shovel and nothing else. `basic` adds one pistol at `PISTOL_AMMO` and 2
  grenades. `all` is every weapon at `max_stack` plus a full battery.

## Notes

- **`round_seconds` becomes the room's.** It is `Config`'s today; the lobby's value
  overrides it for that room and the env var stays as the default. Checks that shorten a
  round through the environment must keep working — grep for them before you move it.
- The kit is `grant_dev_loadout`'s shape but is **not** `dev_loadout`: that one is a
  development switch off by default (`config.rs` says so and it is still true). One
  function, two callers, one enum — do not fork it.
- Out-of-range or unknown values are **refused with a reason**, not clamped. `docs/61`
  §3: the server already knows which of the answers it was.
- A `Disabled`-bots private lobby still needs a start rule: §E3's "every seated human is
  ready" is unchanged and is the whole rule. It does not fall back to bots.
- Validate against the settings the room actually holds, not the ones the client sent
  back.

## Tests

- Each setting: host changes it, `lobby_state` shows it, every seat's ready flag is
  cleared. Control: a **non-host** attempt is refused and changes nothing.
- Bots off: a private match with one human starts with zero bots and stays at zero for
  30 s of ticks. Control: bots on, same seat count, spawns them.
- Each kit, asserted on the inventory at spawn and again after a respawn: `none` is one
  item, `basic` is three stacks with the ammo pinned to constants, `all` holds every
  non-retired weapon at `max_stack`.
- `round_seconds`: a room set to `MIN` ends its round at `MIN`; below `MIN` and above
  `MAX` are refused; a value off the step is refused.
- A settings change is in the replay, and re-running the replay reproduces the same match.
- Public lobbies reject all three commands.
