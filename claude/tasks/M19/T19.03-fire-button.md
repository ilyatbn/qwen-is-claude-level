# T19.03 — Hold to empty the clip, and both buttons fire (v7)

Milestone: M19 · Depends on: T19.01 · Size: ~200 lines

## Read first
- `docs/75-amendments-v7.md` §F3, §F4.1
- `client/src/scenes/GameScene.ts` — the `pointerdown` handler and `conn.sendFire()`
- `crates/game-wasm/src/lib.rs` — `item_registry_json`

## Deliverable

Three changes to how a click becomes a shot:

- **Hold to repeat.** While a mouse button is held and the selected weapon is `auto`,
  fire every `cooldown` seconds until release or an empty stack. Non-auto weapons fire
  once per press, exactly as today.
- **Both mouse buttons fire**, identically.
- **The backpack moves to `Tab`** and keeps every other §C10 behaviour.
- `item_registry_json` gains `auto` and `cooldown` per weapon, from the weapon def. The
  client reads the cadence; it does not carry a table of its own.

## Notes

- The server's `fire_ready_at` gate does not move and is the authority. The client repeat
  is a *cadence*, not a permission — if the two disagree the server wins and the extra
  request is refused, which is the correct outcome and not a bug to paper over.
- Do not send a fire request every frame and let the server refuse it: that is 60 msg/s
  per player for a 10/s weapon. Rate-limit at the weapon's own cooldown.
- Sampling: `pointerdown` is an event and holding is a state. This has to read
  `activePointer` **every frame**, for the reason `localInput.ts`'s header already gives
  about held keys — an event-driven repeat stops the moment nothing changes.
- Right-click had a `pointerdown` early-return that opened the backpack. Deleting it is
  the change; make sure the fire path is not still behind `leftButtonDown()`.
- Check `SandboxScene` for the same right-button branch, and the escape menu for a `Tab`
  binding that already exists.

## Tests

- Unit (pure): a repeat clock at `SMG_COOLDOWN` held for 1.0 s yields the number of shots
  the cooldown allows, pinned to the constant. Control: the same hold on a **non-auto**
  weapon yields exactly one.
- Unit: releasing stops it; an empty stack stops it.
- Unit: the registry view exposes `auto` and `cooldown`, and the auto set is exactly
  `{smg, machinegun, laser_smg}` — asserted against the parsed registry, not a literal.
- e2e: hold the button on an SMG for one second in a real game and the server's shot
  count matches the cadence; the same hold on a pistol fires once.
- e2e: right-click fires and does **not** open the backpack; `Tab` opens the backpack.
