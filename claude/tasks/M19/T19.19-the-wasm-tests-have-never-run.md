# T19.19 — Fourteen wasm tests have never run (found by T19.07)

Milestone: M19 · Depends on: nothing · Size: unknown until the fourteen are read

## What was measured

`crates/game-wasm/src/lib.rs` holds **14 `#[wasm_bindgen_test]`s and 3 plain `#[test]`s**.
`cargo test -p game-wasm --lib` reports **3 passed**. The gate runs `cargo test
--workspace` and nothing else against that crate, so **the fourteen have not executed in
any gate since M3.**

This is not an inference. `lib.rs:1212` already says so in a doc comment — *"the ones
below need `wasm-pack test` and `cargo test -p game-wasm` runs **zero** of them"* — and
the gate log for `f474f2d` shows `game_wasm` running three tests. A new assertion written
beside them inherits the same fate; the §F7 bounds check
(`constants_json_carries_the_private_round_length_bounds`) was deliberately written as a
plain `#[test]` for that reason.

## Why it matters

`constants_json` is the only route by which the client learns any tunable, and
`constants_json_carries_the_viewport_and_camera_values` is the assertion that it carries
anything at all. It has never run. §A19's whole claim — that a renderer cannot drift from
a constant because a test pins the crossing — rests on a test that does not execute.

## Deliverable

**First, read what the fourteen actually assert and say so in the journal.** Anything they
alone cover is the real exposure and is unprotected today; that list is the valuable half
of this task and must come before either repair.

Then one of:

- **Wire `wasm-pack test --node` into `scripts/check.sh`**, if the fourteen need a real
  wasm target (`wasm-bindgen` types, `js_sys`, memory growth). Budget it: the gate is
  ~35 minutes and `docs/72` §C2's ceiling is not negotiable.
- **Convert the ones that do not need a browser to plain `#[test]`.** Most assertions on
  `constants_json`, `registry_json` and `weather_json` are string-and-`serde_json` work
  that runs natively; the sandbox `GameCore` methods may too.

Do not do both halves blind: a `wasm-pack` stage that adds four minutes to buy three
assertions already reachable natively is the wrong trade, and the read above is what
decides.

## Tests

- Whatever lands, **falsify it**: break one constant in `constants_json` and show the
  suite goes red. Today it does not.
- A count assertion beside the runner, in the shape of
  `every_command_really_is_every_command`: the number of tests the gate executes against
  `game-wasm`, so a test that silently stops running is a red rather than a silence.
