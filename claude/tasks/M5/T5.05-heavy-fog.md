## Deliverable

```rust
pub struct HeavyFog { started_at: f32 }

impl HeavyFog {
    pub fn new(now: f32) -> Self;

    /// 0.0 (clear) .. 1.0 (full fog). Ramps in and out over FOG_RAMP.
    pub fn strength(&self, now: f32) -> f32;

    /// The FoV multiplier this fog contributes: lerp(1.0, FOV_FOG_MULT, strength).
    pub fn fov_multiplier(&self, now: f32) -> f32;
}
```

The strength curve over `FOG_DURATION` (15 s):
```
0 .. FOG_RAMP                          ramp 0 → 1  (smoothstep)
FOG_RAMP .. DURATION-FOG_RAMP          hold at 1
DURATION-FOG_RAMP .. DURATION          ramp 1 → 0
after DURATION                         0
```

## Notes

The smallest effect in the milestone, and the only one that deals no damage. Its
whole job is visibility pressure, and it is the only effect that changes **daytime**
combat.

It stacks **multiplicatively** with night (`docs/14-daynight-visibility.md` §3), so
a foggy night gives `FOV_NIGHT * 0.45` ≈ 99 px of visibility — about three player
heights. That is the scariest the game gets, it lasts 15 seconds, and it briefly
makes the flashlight the most valuable item on the map. The multiplicative stacking
is the design, not an accident of the formula.

Use `smoothstep` from `math.rs` for the ramps rather than a linear fade — a linear
fog fade has visible corners at the start and end.

This struct holds no RNG and no map reference. It is a pure timer, which makes it
trivially testable and means the client can compute the same value locally from the
effect's start time without needing per-tick updates.

The client renders a scrolling fog sprite layer whose alpha follows `strength`, plus
the FoV change through the lightmap (T3.10). Neither belongs here.

## Tests

- `strength` is 0 at `t = 0`, ramps to 1.0 at exactly `FOG_RAMP` (2 s).
- Holds at exactly 1.0 through the middle.
- Ramps back to 0 at exactly `FOG_DURATION` (15 s).
- Is 0 after `FOG_DURATION`, and stays 0.
- The curve is continuous — no jump larger than one tick's worth of change anywhere.
- The curve is monotonic on each ramp.
- `fov_multiplier` is 1.0 at strength 0 and exactly `FOV_FOG_MULT` (0.45) at
  strength 1.
- Integration with `fovRadius`: full night + full fog gives exactly
  `FOV_NIGHT * FOV_FOG_MULT`. Assert against the product, so a change to either
  constant is caught.
- Fog applies to every player equally (it is global, not per-player) — assert the
  multiplier does not depend on any player argument.
- No damage is dealt: run a full fog with players present and assert every health
  value is unchanged.
