**Part 2 — lava**:
```rust
pub struct Vent { pub id: u32, pub pos: Vec2, pub jet_until: f32, pub burn_until: f32,
                  pub lean: f32 }

pub struct LavaBurst { rng: ChaCha8Rng, vents: Vec<Vent>, opened: bool }

impl LavaBurst {
    pub fn new(seed: u64, map: &Map, now: f32) -> Self;   // picks vent positions
    pub fn vents(&self) -> &[Vent];
    /// Opens the channels on the first active tick, then damages each tick.
    pub fn tick(&mut self, map: &mut Map, players: &mut [PlayerHitTarget],
                active: bool, now: f32, dt: f32) -> Vec<CarveResult>;
}
```

Per vent: on activation, `carve_capsule` from the vent point to `3 × LAVA_CHANNEL_R`
below it, radius `LAVA_CHANNEL_R` (24). Then a jet for `LAVA_JET_DURATION` (3 s)
dealing `LAVA_JET_DPS` (10) to players in a cone (upward, random lean up to 30°,
height ~180 px). Then burning ground for `LAVA_BURN_DURATION` (3 s), radius
`LAVA_BURN_RADIUS` (28), dealing `LAVA_BURN_DPS` (8).

## Notes

Total lifetime per vent is 9 s: 3 s telegraph (the scheduler's) + 3 s jet + 3 s
burn. Getting this wrong by a phase is the most likely error — write the timeline
out in a comment.

Vent positions come from `map.meta.surface_points`, spread out (minimum 200 px
apart). This effect specifically punishes players who have dug themselves a hole, so
preferring points in depressions would be a nice refinement — but not in v1, and
uniform-but-spread is fine.

The jet cone: origin at the vent, direction `up + lean`, half-angle ~20°, length
180 px. Test player AABB centres against the cone; exact cone-box intersection is
not worth it here.

Damage is per-tick (`dps * dt`), through `apply_damage` with
`DamageSource::Weather(EffectKind::LavaBurst)`.

`carve_capsule` is used exactly once in v1, but it is the primitive that future
drills and beams need (`docs/11-map-destruction.md` §9), which is why it goes in
`carve.rs` alongside `carve_circle` rather than being inlined here.

## Tests

**`carve_capsule`:**
- A capsule from (100,100) to (100,200) with r=10 clears a 20-px-wide vertical band.
- A horizontal capsule clears a horizontal band.
- A diagonal capsule clears a continuous band with **no gaps** — assert every point
  along the line is air afterwards. Gaps from an under-sampled sweep are the classic
  bug.
- A zero-length capsule equals `carve_circle`.
- It respects bedrock and walls, exactly like `carve_circle`.
- The coarse grid stays exact afterwards (`coarse.verify` is `Ok`).
- Dirty chunks cover the whole swept bounding box.

**Lava:**
- `LAVA_VENTS_MIN..=LAVA_VENTS_MAX` (3–6) vents are chosen, at least 200 px apart.
- Every vent is on a surface point.
- Activation carves a channel at each vent — `count_solid` drops.
- The jet damages a player inside the cone at `LAVA_JET_DPS` per second.
- A player outside the cone takes nothing.
- The jet stops after exactly `LAVA_JET_DURATION`.
- Burning ground damages at `LAVA_BURN_DPS` for exactly `LAVA_BURN_DURATION`, then
  stops.
- Total damage to a player standing on a vent for the whole event is
  `10*3 + 8*3` = 54, within a tick's tolerance.
- A shielded player takes half.
- Determinism: the same seed produces the same vents and leans.
