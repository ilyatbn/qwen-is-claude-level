# T13.02 — Assert on rendered pixels (v4)

Milestone: M13 · Depends on: T13.01 · Size: ~200 lines

## Read first
- `docs/72-amendments-v4.md` §C0, §C2
- `docs/70-amendments-v2.md` §A15, §A16 (sample where the change is)

## Why

905 tests and 20 e2e specs missed four "I cannot see it" bugs, because every
assertion about the world asserts on **simulation state** (mask checksums, solid
pixel counts) or **client bookkeeping** (draw counters, tracked-vs-drawn), and none
on the **rendered frame**. This is §A15/§B21 for the fifth time: *fog's formula was
always right; nothing tested that the number reached the screen.*

## Touch only
- `scripts/checks/pixels.mjs` (new — the shared harness)
- `scripts/e2e.mjs`

## Deliverable

A reusable harness for pixel assertions, and specs built on it:

```js
samplePatch(page, {x, y, w, h})    // → mean rgb + a stable digest
assertChanged(before, after, opts) // → with a named control region
```

Read pixels from a **screenshot**, not the WebGL canvas — Phaser does not preserve
the drawing buffer, and `night_darkens_the_world.mjs` already does this correctly.

## Notes

- **Every assertion carries a control**: a region that must *not* change, or a frame
  with the feature off. Without it the test passes for a canvas that is always
  different (this is how §A16's mid-band lesson was learned).
- Sample **where the change is**. A whole-frame mean is dominated by the sky and
  hides everything (§A15).
- Frame the subject before shooting: a screenshot that does not contain its subject
  is not evidence (§A22), and a transient effect can be shorter than a screenshot
  round-trip (§A3's tracer took three attempts).

## Tests

- The harness itself: a synthetic page with a known changing rectangle passes; the
  same page with nothing changing fails.
- `assertChanged` fails when the control region also changed.

## Done when

```sh
node scripts/e2e.mjs pixels
```
