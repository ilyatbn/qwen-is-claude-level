## Deliverable

A script that downloads the four Kenney CC0 packs into
`assets/vendor/kenney/<slug>/`:

| slug | used for |
|---|---|
| `platformer-characters` | player skins |
| `particle-pack` | explosions, smoke, rain, embers |
| `pixel-platformer` | items, crates, props, weapons |
| `ui-pack` | inventory, HUD, buttons |

Per pack:
1. fetch `https://kenney.nl/assets/<slug>`;
2. extract the first `.zip` href from the HTML;
3. download it;
4. unzip into `assets/vendor/kenney/<slug>/`;
5. remove the zip;
6. **verify `LICENSE.txt` exists** and fail loudly if it does not.

Idempotent — an existing pack directory is skipped unless `--force` is passed.

`assets/vendor/README.md` records each pack: name, source URL, licence, date
fetched.

## Notes

**Do not hard-code the zip URLs.** Kenney's download links contain a content hash
that changes whenever a pack is updated, so a pinned URL silently 404s months later.
Scraping the first `.zip` href is ugly but it is the stable option, and it is worth
a comment explaining why.

**Failure must be clear and must not block development.** If the network is
unavailable or the site restructures, print the pack page URLs and the exact target
directories, tell the user to download manually, and exit non-zero — but make it
obvious the game still runs, because the procedural fallback (T7.05) covers every
missing asset. A newcomer hitting a hard failure here should not conclude the
project is broken.

`set -euo pipefail`. Use `curl -fsSL` and check the exit status of every step; a
truncated download that unzips to garbage is worse than a clean failure.

The licence check in step 6 is not bureaucracy — `docs/51-assets.md` §8 requires
every vendored pack to keep its licence, and a pack whose structure changed such
that `LICENSE.txt` moved is exactly when you want to notice.

Assets are **committed** after fetching, so a fresh clone needs no network.

## Tests

No unit tests; this is a shell script. Manual verification, and report on each:

1. Run on a clean tree — all four packs download and unzip.
2. Every pack directory contains a `LICENSE.txt`.
3. Run again — all four are skipped, and the script exits 0 quickly.
4. Run with `--force` — all four re-download.
5. Simulate a failure (point one slug at a nonexistent page) — the script fails with
   a clear message naming the pack and the manual URL, and does not leave a partial
   directory behind.
6. `assets/vendor/README.md` lists all four packs with their URLs, licences and
   dates.
7. Total size of `assets/vendor/` is reported; confirm it is within the 12 MB budget
   from `docs/51-assets.md` §7.
