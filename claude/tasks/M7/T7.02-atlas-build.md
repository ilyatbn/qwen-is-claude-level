## Deliverable

**`assets/atlas-map.json`** — hand-written, checked in. Maps vendor PNGs to our
frame names, grouped by atlas:

```json
{
  "chars":   { "character_green_idle": "vendor/kenney/platformer-characters/PNG/…png" },
  "weapons": { "bazooka_default": "…" },
  "items":   { "medkit": "…" },
  "fx":      { "explosion_a": "…" },
  "ui":      { "slot_frame": "…" }
}
```

**`scripts/build-atlas.mjs`** — reads the mapping, packs each group with
`free-tex-packer-core`, writes `assets/atlas/<name>.png` + `.json` in Phaser's JSON
Hash format.

**`assets/manifest.json`** — the load list from `docs/51-assets.md` §6.

## Notes

**Frame names are ours, not Kenney's.** `character_green_walk_a`, not
`PNG/Characters/character_green_walk1.png`. That indirection is the whole point: a
pack can be swapped, or a frame re-sourced, without touching `skins.json` or any
code. Do not shortcut it by using the vendor filenames.

Atlases are **committed**, so a fresh clone runs without Node asset tooling. The
build script is only needed when the art changes.

Cap each atlas at 2048×2048 (`docs/51-assets.md` §7). If a group overflows, the
script should fail with a clear message rather than silently producing a second page
that nothing loads.

Five atlases: `chars`, `weapons`, `items`, `fx`, `ui`. Do not merge them into one —
per-category atlases mean a change to UI art does not invalidate the character
atlas's cache.

The script must be **idempotent and deterministic**: the same inputs produce
byte-identical output, so an unchanged rebuild is not a diff. Sort the frame list
before packing; most packers are order-sensitive.

A mapping entry pointing at a missing file is an error, not a warning — a silently
skipped frame becomes a magenta placeholder in game with no clue why.

`manifest.audio` stays empty in v1; it exists so the shape is settled
(`docs/51-assets.md` §10).

## Tests

`scripts/verify-assets.mjs` (written back in T0.08) now does real work. Extend it if
needed, and add:

- Every path in `atlas-map.json` exists on disk.
- Every atlas listed in `manifest.json` has both its `.png` and `.json`.
- Every atlas JSON parses and its frames match the mapping's frame names.
- No atlas PNG exceeds 2048×2048.
- Total `assets/` size is under the 12 MB budget.
- Running `build-atlas.mjs` twice produces byte-identical output.
- A mapping entry pointing at a missing file fails the build with a message naming
  the entry.

## Done when

```sh
node scripts/build-atlas.mjs && node scripts/verify-assets.mjs && ./scripts/check.sh
```
