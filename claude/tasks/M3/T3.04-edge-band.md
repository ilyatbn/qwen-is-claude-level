## Deliverable

```ts
/** Mark the top EDGE_BAND_PX solid pixels below each air→solid transition. */
export function buildEdgeStencil(core: Core, chunkX: number, chunkY: number,
                                 scratch: BakeScratch): void;

/** Extended bake: fill, punch, then composite the edge texture over the band. */
export function bakeChunk(
  texture: Phaser.Textures.CanvasTexture,
  fillImage: CanvasImageSource,
  edgeImage: CanvasImageSource,
  chunkX: number, chunkY: number,
  core: Core, scratch: BakeScratch,
): void;
```

Algorithm — one downward pass per column, no distance transform:

```
for each column x in the chunk:
    run = 0
    for y from chunkTop-EDGE_BAND_PX to chunkBottom:
        if solid(x, y):
            if run < EDGE_BAND_PX: mark (x, y) as edge
            run += 1
        else:
            run = 0
```

Composite the edge texture over the fill with `source-atop`, masked by this stencil.

## Notes

**Only upward-facing surfaces get the band.** The single-pass rule above achieves
that for free: the run counter resets on air, so the band appears below an air→solid
transition and nowhere else. The undersides of overhangs stay dark, which is what
sells the depth in the Worms screenshots. Do not "improve" this into a symmetric
outline — a band on every surface makes the terrain look like a sticker.

**Start the scan `EDGE_BAND_PX` rows above the chunk's top edge.** Otherwise a
column that is solid at the chunk boundary starts its run at 0 and paints a false
band across the seam — a visible horizontal line at every chunk boundary. This is
the seam handling the doc's §2 warns about, and it is the most likely bug here.

Reuse `BakeScratch` for the edge stencil too; add a second scratch canvas rather
than allocating per bake.

## Tests

Extend `chunkBake.test.ts`:

- A flat floor: the top `EDGE_BAND_PX` rows of solid are marked, the rows below are
  not.
- A solid pixel with air below but rock above is **not** marked (undersides stay
  dark).
- A column of solid `EDGE_BAND_PX - 1` tall: every pixel is marked.
- A column of solid 100 px tall: exactly the top `EDGE_BAND_PX` are marked.
- Two separate solid runs in one column (a ledge above a floor): **both** get a
  band.
- **Seam case**: a column that is continuously solid from above the chunk's top edge
  down through it gets **no** band inside this chunk. This is the test that pins the
  margin handling.
- A fully empty chunk marks nothing.
- A fully solid chunk marks nothing (no air→solid transition inside it, given the
  margin).
