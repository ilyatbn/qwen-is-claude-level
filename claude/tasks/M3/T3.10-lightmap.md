## Deliverable

```ts
export interface LightSource {
  x: number; y: number; radius: number;
  kind: 'radial' | 'cone';
  angle?: number; coneDeg?: number;
  intensity: number;   // 0..1
}

export class Lightmap {
  constructor(scene: Phaser.Scene, nightColor: number);
  /** Called every frame. Skips all work when darkness is 0 and no fog. */
  render(camera: Phaser.Cameras.Scene2D.Camera, darkness: number,
         sources: readonly LightSource[]): void;
  destroy(): void;
  readonly stats: { drawsLastFrame: number };
}

/** Pure. The FoV formula from docs/14-daynight-visibility.md §3. */
export function fovRadius(opts: {
  darkness: number; fogActive: boolean; health: number; flashlightOn: boolean;
}): number;
```

## Notes

The formula, exactly:
```
fov = lerp(FOV_DAY, FOV_NIGHT, darkness / NIGHT_DARKNESS)
    * (fogActive ? FOV_FOG_MULT : 1)
    * lerp(FOV_HEALTH_MIN_MULT, 1, clamp01(health / BASE_HEALTH))
    * (flashlightOn ? FLASHLIGHT_AMBIENT_MULT : 1)
```
Keep it a pure exported function — it is the one genuinely testable piece here, and
the server will need the identical formula for visibility culling later.

**Generate the gradient and cone textures once, at construction.** Building a
radial gradient per light per frame is the obvious way to write this and it will
halve your frame rate. One 256×256 radial-gradient texture scaled per source, and
one cone texture rotated per source, is all that is needed.

`FOV_EDGE_SOFTNESS` (0.35) means the gradient is opaque for the inner 65 % of the
radius and fades over the outer 35 %. Bake that into the gradient texture's colour
stops.

**Skip the entire pass when `darkness === 0` and no fog is active.** In daylight
this layer should cost literally nothing — `setVisible(false)` and return before
any draw call. `stats.drawsLastFrame` must be 0 then, and T3.11 displays it.

The render texture is screen-sized with `scrollFactor` 0 at depth 50; light source
positions are converted to screen space before drawing. Drawing a world-sized render
texture would be enormously wasteful.

Erase with `BlendModes.ERASE`, then draw the whole layer with `MULTIPLY`.

Add two sliders to the sandbox — darkness 0..1 and a fog toggle — so visibility can
be checked instantly without waiting 60 seconds for nightfall.

## Tests

`client/src/render/lightmap.test.ts` — `fovRadius` is the target:

- Day, full health, no fog, no flashlight → exactly `FOV_DAY`.
- Full night (`darkness = NIGHT_DARKNESS`), full health → exactly `FOV_NIGHT`.
- Full night + fog → `FOV_NIGHT * FOV_FOG_MULT`.
- Day + fog → `FOV_DAY * FOV_FOG_MULT`.
- 0 health at day → `FOV_DAY * FOV_HEALTH_MIN_MULT`.
- Flashlight on → the ambient radius shrinks by exactly `FLASHLIGHT_AMBIENT_MULT`.
- All four modifiers together multiply, in any order (assert against the explicit
  product).
- Health above `BASE_HEALTH` (overheal) does not increase FoV beyond 1.0 — the
  clamp holds.
- `darkness = 0` → `FOV_DAY` regardless of the other night parameters.

Plus, with the render texture stubbed:
- `render` with `darkness = 0` and no fog performs zero draws.
- `render` with `darkness = 0.5` draws the fill plus one erase per source.
