export type SkyPhase = 'morning'|'day'|'afternoon'|'evening'|'night'|'dawn'
export function cycleU(roundTime: number): number          // (t / 120) mod 1
export function skyPhase(u: number): SkyPhase
export function skyColors(u: number): { top: number; bottom: number }
export function bodyPositions(u: number, w: number, h: number):
  { sun: {x:number;y:number;a:number} | null, moon: {x:number;y:number;a:number} | null }
export class SkyLayer { constructor(scene: Phaser.Scene); update(roundTime: number, darkness: number): void }

## Notes

**Module split is mandatory — see `docs/70-amendments-v2.md` §A8.** Phaser cannot be
imported under vitest (node: `window is not defined`; jsdom: null 2d context). Pure
functions go in the `-math`/`-state` file; the Phaser class imports that file and is
never imported by a test.

- `skyColors` interpolates the keyframe table in `docs/70-amendments-v2.md` §A4 in
  **linear RGB**, wrapping from the last keyframe back to the first.
- The gradient is drawn once into a 2×256 CanvasTexture and stretched to the
  viewport, re-baked only when the interpolated colours actually change (compare the
  packed ints), not every frame.
- Sun/moon `a` is alpha: fade in/out over the first and last 8 % of their arcs so
  they do not pop at the horizon.
- Stars: `STAR_COUNT` positions from a fixed seed, alpha
  `clamp((u - STAR_FADE_START) ... )` combined with `darkness / NIGHT_DARKNESS`,
  twinkle from a per-star phase. Drawn on the sky layer, scroll factor
  `SKY_BODY_PARALLAX`.
- The sky layer is `scrollFactor(0)` for the gradient and `SKY_BODY_PARALLAX` for
  bodies and stars; it must sit at depth −30, below everything.

## Tests (vitest, pure functions only)

- `cycleU` wraps: `cycleU(0) === 0`, `cycleU(120) === 0`, `cycleU(180) === 0.5`.
- `skyPhase` returns each of the six names somewhere in `0..1`, and its boundaries
  match the table exactly.
- `skyColors` is continuous: sampling `u` at 1000 points, no adjacent pair differs
  by more than 12 per channel — including across the 1.0 → 0.0 wrap.
- `skyColors` at each keyframe `u` returns that keyframe's colours exactly.
- `bodyPositions`: sun is non-null exactly on `[0, 0.55]`, moon on `[0.5, 1.0]`;
  both are above the horizon at their mid-arc and at/below it at their ends.
