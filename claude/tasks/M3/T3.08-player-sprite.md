## Deliverable

```ts
export type AnimState = 'idle' | 'walk' | 'jump' | 'fall' | 'jetpack' | 'hurt' | 'dead';

/** Pure. Derived from snapshot flags and velocity — never sent over the wire. */
export function deriveAnimState(p: {
  alive: boolean; grounded: boolean; jetpack: boolean; vx: number; vy: number;
}): AnimState;

export class PlayerView {
  constructor(scene: Phaser.Scene, skinId: number);
  setState(x: number, y: number, vx: number, vy: number, aim: number,
           flags: PlayerFlags): void;
  setName(name: string): void;
  destroy(): void;
  readonly container: Phaser.GameObjects.Container;
}
```

The container holds `body`, `weapon` (a placeholder until T7.04) and `overlays`
(shield bubble, i-frame flash, name label), as in the doc's §3.

## Notes

`deriveAnimState` implements the doc's table exactly, **in that priority order**:
dead → jetpack → jump (`!grounded && vy < 0`) → fall (`!grounded`) → walk
(`grounded && |vx| > 10`) → idle. Order matters: a dead player who is also falling
must render as dead.

It is a pure function taking a plain object, so it is unit-testable without Phaser.
Keep it that way — it is the only genuinely testable thing in this file.

**Facing comes from the aim angle, not velocity** (`docs/22-aiming-crosshair.md`
§4): `cos(aim) < 0` means face left. Walking right while shooting left must look
right, and it is a case people forget until it looks wrong on screen.

Walk animation speed scales with `|vx|`, so a wounded, slowed player visibly
trudges. `anim.msPerFrame = base * (WALK_SPEED / max(|vx|, 1))`, clamped.

**Placeholder fallback is required now, not later.** There is no art until M7, so
every frame lookup must fall back to a generated coloured rectangle
(`PLAYER_W × PLAYER_H`, tinted by skin id) and log the missing key exactly once. If
this file throws on a missing texture, M3 through M6 cannot run at all.

`anchor.y` is 0.9 per the skin registry, so the sprite's feet sit at the bottom of
the 16×28 AABB. Until `skins.json` exists (T7.03), hard-code 0.9 with a comment
pointing at `docs/50-sprites-skins.md` §3.

## Tests

`client/src/render/playerView.test.ts` — `deriveAnimState` only:

- Dead + falling → `dead` (priority order).
- Jetpack active while grounded → `jetpack`.
- `!grounded, vy < 0` → `jump`.
- `!grounded, vy > 0` → `fall`.
- `grounded, |vx| = 50` → `walk`.
- `grounded, |vx| = 5` → `idle` (below the threshold).
- `grounded, vx = 0` → `idle`.
- Exactly at the threshold (`|vx| = 10`) → `idle`, not `walk` (assert the boundary).

Plus, with the texture manager stubbed:
- A missing frame key returns the placeholder and logs exactly once, even when
  requested fifty times.
- `destroy` removes every child of the container.
