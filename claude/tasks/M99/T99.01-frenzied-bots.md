# T99.01 — Frenzied bots for trailer footage (`DEV_BOT_FRENZY`)

Milestone: M99 (promotional) · Size: ~80 lines · Owner ask 2026-09-30: "make bots extremely aggressive, know each
other's locations so it looks fun."

**Promo only, off by default.** A real round never sees it: a bot that knows where you are through a mountain is a
cheat. Not in the replay header (`dev_flashlight`'s reason).

## Do
- `Bot::frenzied(on)` (`game-core/src/bots/mod.rs`): `choose_goal`'s enemy search has no range (the nearest living
  enemy anywhere on the map) and nobody flees. Weapon range and line of sight in `should_fire` are unchanged — a bot
  still has to get there to shoot.
- `DEV_BOT_FRENZY=1` (`game-server/src/config.rs`, in `summary()`), wired where `room.rs` seats bots.
- Trailer server: `DEV_BOT_FRENZY=1 DEV_LOADOUT=1 BOT_COUNT=5 BOT_SKILL=1` (rockets, flamethrower, molotovs, lasers).

## Tests
- `bots::tests::a_frenzied_bot_hunts_an_enemy_out_of_sight_and_never_flees` — control: the same bot unfrenzied, same
  world, does not engage at 3× `BOT_ENGAGE_RANGE` and does flee when hurt. Planted (`f32::INFINITY` →
  `BOT_ENGAGE_RANGE`): red.
- `config::tests::dev_bot_frenzy_is_off_unless_asked_for_and_shows_in_the_summary`.

## Touch only
`crates/game-core/src/bots/mod.rs`, `crates/game-server/src/config.rs`, `crates/game-server/src/room.rs`, `client/src/scenes/GameScene.ts` (two e2e handles, T99.02), `scripts/lib/affected{,.test}.mjs` (`promo/` → nothing), `promo/`, `tasks/`

`cargo test -p game-core --lib frenzied && cargo test -p game-server --lib dev_bot_frenzy` exits 0.
