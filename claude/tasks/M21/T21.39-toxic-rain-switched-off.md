## Decisions

- **`WEATHER=toxic` is refused**, not mapped to `off`. The config already refuses every
  unknown spelling for the reason its test states (a silent default fails somewhere else an hour
  later); a check asking for toxic rain and getting clear sky would be exactly that.
- **Odds with the switch off** (weights 3:2:2 meteor/lava/fog, never the same twice): the
  stationary shares are 0.375 / 0.3125 / 0.3125 (from 0.284/0.284/0.216/0.216 with toxic).
