Milestone: M21 · Depends on: nothing · Size: three small items, one commit each

   a gate ("held a for 4000 ms … stopped 34 px short"), alone at `e9a4333` ("two rockets in a
   row left x=1037 at 26 px"), and alone with T21.18's code reverted ("x=1040 at 19 px", no death

3. **`MINE_W` / `MINE_H` live in `weapons/placed.rs`**, not `constants.rs` (JOURNAL gap note).

## Rulings (coordinator, reversible)

- **`void`: fix the game if the game is wrong, the check if the check is wrong** — never by
  weakening what it proves: a player digs through the floor, falls out of the world, and dies

  consecutive green runs alone, and falsify it.
- **Docker: the image or compose file makes recording work** on a bind mount whatever owns the
  host directory. The server's startup log names where replays go. If `RECORD_REPLAY=1` and the
  directory is not writable, the server says so **once, at startup**, loudly — not per room.
- **Mine size moves to `constants.rs`.** Every reader is grepped in every language, including
  `scripts/`. If the client needs it, it gets the three-file export.

## Causes, as verified

1. **`void` — the check fired before its aim reached the server.** `fire()` sends a bare
   `fire` event; the angle travels in the input packets the scene samples once a frame, so
   `mouse.move` then `fire()` in the same turn shoots along the previous aim. Instrumented on
   seed 5, 3 runs of 3: rocket 1 spawned and exploded (`ownProjectileSpawns` 0→1, `explosions`
   0→1) and carved 0 px in a 281×324 window round player and column; rocket 2 at the same aim
   carved 2011 px. Two duds in a row are the parked "two rockets in a row left x=… at N px".
   The dig column also moves with the walk's ±8 px arrival, next to a pit wall at x=1096, which
   is plausibly the gate's "stopped 34 px short" under load; not reproduced alone. Game
   unchanged. Fix: wait for `inputsSent` to move, then two server ticks, then fire.
2. **Docker** — a bind mount hides the image's `game`-owned `/recordings`; the host
   `recordings/` Docker created is `root:root 755` (measured), and the server runs as uid 10001.
   Reproduced: `touch` into a bind mount as the image's user → `Permission denied`. Fix: a
   one-shot root `recordings-init` service chowns the mount; the server image stays non-root.
   The server now logs `replay_dir=` in its summary and probes writability once at startup.
3. **Mine size** — no reader outside `placed.rs` in any language; the client does not need it.
