# T21.27 — Bury the sprite clouds (v9)

Milestone: M21 · Depends on: T21.18 item 1 (`66f3514`) · Size: small

## Why

T21.18's cloud commit replaced the sprite clouds with a shader and **deliberately
left their code standing**, to keep one commit to one effect. That was the right
call then and is the wrong state to stay in.

Left behind, named by the builder who left them:

- `client/src/render/clouds-math.ts` **and its test file**
- `sky-math.ts`'s `cloudField`, `cloudX`, `cloudTwinX`, `cloudSprites`
- the `clouds` atlas, still loaded by the manifest and never drawn

## The point, and it is not tidiness

**These have tests, and the tests pass.** That is strictly worse than untested
dead code, because a green test reads as a guarded invariant. Anyone counting
coverage here counts assertions that protect a picture no longer on screen, and
anyone changing `sky-math.ts` will keep these functions working for no reason.

The mirror of this project's own rule: *grep for the production callers of
anything you build.* The same grep retires what nothing calls.

## The work

1. `grep -rn` each symbol across `client/src` and `scripts/` and confirm **zero**
   production callers — a test calling it is not a caller. Paste the greps.
2. Delete the code and its tests together. A test deleted with its subject is not
   a test removed, and the journal should say the count fell and why: *a test
   count going up is not evidence that no test was removed*, and the same honesty
   applies going down.
3. Drop the `clouds` atlas from the manifest **only if** nothing else draws from
   it. Check the skins, decorations and objects paths before assuming.
4. Confirm the game still starts with no art at all (`docs/50` §8) — removing a
   manifest entry is exactly the kind of change that breaks the empty path.

## Watch for

- `living-sky.mjs` already had ~400 lines removed in the cloud commit for this
  same reason. Check nothing it kept still reaches the doomed symbols.
- If any of these turn out to have a live caller, **stop and say so** — that is a
  finding about the cloud commit, not a reason to force the deletion.

## Done when

```sh
npm --prefix client test -- --run && ./scripts/check.sh
```
