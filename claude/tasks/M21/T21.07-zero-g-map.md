# T21.07 — Zero gravity: the map (v9)

Milestone: M21 · Depends on: **T21.06** · Size: **large** — a second map generator

Asked for: *"this mode reshapes the map and how it's generated. Instead of normal, it now
creates a thin layer of 'land' around the map edges. It can be squared, a circle, or some
other shape that wraps everyone together. Then you generate tons of tiny islands inside this
square but enough space to float between them, like stars. You can generate objects anywhere
since there's no 'up'."*

## Read first
- `crates/game-core/src/map/gen/` — the whole generator, and **`surface.rs` especially**
- `crates/game-core/tests/golden.rs:50-60` — what is digested, and why this task changes it
- `crates/game-core/src/map/gen/objects.rs` (or equivalent) — object placement's up-assumption

## ⚠ This changes golden hashes by design — say so before you run the gate

`golden.rs` digests **map generation** — mask, theme, wind, spawns, buried slots, objects. A
second generator does not change existing hashes *if* it is a genuinely separate path taken
only when the mode is on. **Verify that rather than assume it**: if the new mode perturbs the
shared RNG stream — an extra draw, a different call order — every existing golden moves, and
that is a red gate that looks like a regression.

This is the same class as T20.06's discovery that zeroing five weapon weights shifted every
later draw in a shared sub-stream. **Give the zero-g generator its own RNG substream.**

## Deliverable

- A generator that produces: a **closed boundary** of thin land (square, circle, or another
  wrapping shape — pick one, build one, and say why the others were not), and **many small
  islands** inside it with float-through space between them.
- **Spawn points that work** — the existing generator derives them from a surface. There is no
  surface here. This is not a detail; a mode where players spawn inside rock or outside the
  boundary is unplayable, and `surface_points` is read by more than spawning.
- **Objects placed anywhere**, since there is no up. Check what else assumes up: decorations,
  buried items, tombstones (which fall), crates (which fall — `is_falling_crate`), and the
  minimap.

## The things that will break, none of them obvious

- **`SkyBand` and birds.** `birds.rs:44` derives flight altitude from the map's median column
  top. In a mode with land at the edges, "median column top" is meaningless. Birds either need
  their own answer here or must be off in this mode — **decide**.
- **Weather.** Toxic rain spawns at `SKY_MARGIN` and falls. With no gravity it does not fall,
  and with land at the top it starts inside rock. Meteors likewise. **Weather is arguably off
  in zero-g** — say so explicitly rather than shipping rain that hangs motionless in the sky.
- **The minimap and the camera.** Both assume a wide, short world with ground at the bottom.
- **T21.06's collision rule** is what makes islands playable or lethal. They are the same
  feature; do not tune them apart.

## Notes

- **`MapScale` already varies the map** (Small/Medium/Large), so there is a precedent for the
  generator branching on a config value. Follow it rather than inventing a second entry point.
- This is the task most likely to exceed one file and 250 lines. **If it does, split it and
  say so** — `CLAUDE.md` asks for that explicitly, and "boundary + islands" and "spawns +
  objects" are a natural seam.

## Tests

- A generated zero-g map has a closed boundary — assert it is *closed*, not merely that land
  exists at the edges, because a boundary with a gap is a map players leave.
- Islands exist, are reachable, and have space between them — a population claim over
  **multiple seeds**, not one draw.
- Every spawn point is in open space and inside the boundary, over many seeds.
- **Existing golden hashes are unchanged** when the mode is off. That is the test that catches
  a shared-RNG perturbation, and it is the most important one here.

cargo test -p game-core && cargo test -p game-core --test golden && ./scripts/check.sh
