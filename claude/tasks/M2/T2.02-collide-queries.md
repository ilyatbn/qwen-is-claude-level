## Deliverable

```rust
#[inline]
pub fn solid_at(map: &Map, x: i32, y: i32) -> bool;

/// True if any solid pixel is inside the box. THE hot function in the project.
pub fn aabb_overlaps_solid(map: &Map, aabb: Aabb) -> bool;

/// First solid pixel along a ray, stepping 1 px at a time, up to max_dist.
/// Used by hitscan (T4.11) and the traversal line-of-sight checks.
pub fn raycast(map: &Map, from: Vec2, dir: Vec2, max_dist: f32) -> Option<Vec2>;
```

## Notes

`aabb_overlaps_solid` must use the coarse grid, in this order:

```
for each 8x8 coarse cell the box overlaps:
    match cell_at(...):
        Empty => continue                  // skip, no bits read
        Full  => return true               // decisive, no bits read
        Mixed => test the pixels of this cell that are inside the box
```

On generated terrain the great majority of cells are `Empty` or `Full`, so this
usually returns without reading the mask at all. That is the entire reason the
coarse grid exists — a naive per-pixel loop over a 16×28 box is 448 bit tests per
call, called dozens of times per body per tick.

Get the pixel range from `Aabb::pixel_bounds()` (T0.04). Do not re-derive it.

`raycast` steps by 1 px along the normalised direction. It is not a DDA — a DDA is
faster but the 1-px step matches the sub-stepping guarantee used everywhere else in
the project, and consistency is worth more here than speed. Return the first solid
point, or `None` if the ray leaves the map or exceeds `max_dist`.

## Tests

Build small masks by hand:

- `solid_at` outside the map bounds returns false.
- A box entirely in air: `aabb_overlaps_solid` is false.
- A box entirely in rock: true.
- A box overlapping rock by exactly one pixel at each of the four corners: true, all
  four cases. (Corner cases are where the coarse-cell iteration usually gets its
  bounds wrong.)
- A box one pixel clear of rock on each side: false, all four cases.
- **Coarse consistency**: on a real generated map, `aabb_overlaps_solid` agrees with
  a brute-force per-pixel check for 10 000 random boxes. This is the test that
  proves the coarse fast path is not lying, and it is the most valuable test here.
- A box overlapping only `Empty` cells returns false without reading the mask
  (verify indirectly by constructing a mask where the coarse grid says empty and the
  bits are deliberately corrupted — the function must trust the grid).
- `raycast` straight down from air onto a floor returns the floor's top pixel.
- `raycast` into open air returns `None`.
- `raycast` with `max_dist` shorter than the distance to the wall returns `None`.
- `raycast` starting inside solid returns the start point.
