## Deliverable

```rust
/// How far down the box can move (0..=max_depth px) before it would touch solid.
/// Returns None if there is no ground within max_depth.
pub fn ground_probe(map: &Map, aabb: Aabb, max_depth: i32) -> Option<i32>;

/// Smallest lift in 1..=max_lift that clears an overlap, or None if none does.
/// This is the step-up / slope-climb primitive.
pub fn step_up_clearance(map: &Map, aabb: Aabb, max_lift: i32) -> Option<i32>;

/// Is the box currently resting on ground? (Overlaps nothing, but would if
/// moved 1 px down.)
pub fn is_on_ground(map: &Map, aabb: Aabb) -> bool;
```

## Notes

`ground_probe` returns the **distance to move down**, not an absolute y. Returning
0 means the box is already touching ground; returning `None` means there is nothing
within `max_depth` and the body is genuinely falling.

`step_up_clearance` returns the *smallest* lift that works, not the first one tried
from the top. Lifting more than necessary makes the player visibly hop up slopes.
Test lifts in ascending order, 1 through `max_lift`.

`is_on_ground` must check *overlaps nothing now* as well as *would overlap 1 px
down*. Checking only the second gives `true` for a body already embedded in rock,
which then never resolves.

All three are pure queries — they never mutate the body. Movement resolution
(T2.04, T2.05) is what applies their answers.

These run several times per body per tick, so keep them allocation-free and lean on
`aabb_overlaps_solid`'s coarse fast path rather than writing new pixel loops.

## Tests

Hand-built masks:

- A box resting exactly on a floor: `ground_probe(.., 8)` returns 0, and
  `is_on_ground` is true.
- A box 3 px above a floor: `ground_probe` returns 3.
- A box 20 px above a floor with `max_depth = 8`: returns `None`.
- A box in open air far above anything: returns `None`.
- A box overlapping a 4 px step: `step_up_clearance(.., 6)` returns 4.
- A box overlapping a 7 px step with `max_lift = 6`: returns `None` (it is a wall).
- `step_up_clearance` returns the smallest working lift, not the largest — build a
  case where both 2 and 5 would clear, and assert it returns 2.
- A box with a ceiling directly above cannot step up even into a small overlap.
- `is_on_ground` is false for a box floating 1 px above the floor.
- `is_on_ground` is false for a box embedded in rock.
- On a 30° slope, `ground_probe` returns a value in 0..=`STEP_DOWN` as the box moves
  horizontally across it — this is the property that makes downhill walking smooth
  (used in T2.05).
