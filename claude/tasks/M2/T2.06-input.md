## Deliverable

```rust
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct Input {
    pub seq: u32,
    pub buttons: u8,     // packed, see below
    pub aim: u16,        // quantised angle
}

pub mod button {
    pub const LEFT: u8       = 1 << 0;
    pub const RIGHT: u8      = 1 << 1;
    pub const UP: u8         = 1 << 2;
    pub const DOWN: u8       = 1 << 3;
    pub const JUMP: u8       = 1 << 4;
    pub const FIRE: u8       = 1 << 5;
    pub const FLASHLIGHT: u8 = 1 << 6;
}

impl Input {
    pub fn held(&self, b: u8) -> bool;
    pub fn aim_angle(&self) -> f32;                    // dequantised
    pub fn move_dir(&self) -> f32;                     // -1, 0 or +1 from LEFT/RIGHT
}

/// Edges derived by comparing against the previous tick's input.
#[derive(Clone, Copy, Debug, Default)]
pub struct InputEdges { pub jump_pressed: bool, pub jump_released: bool,
                        pub fire_pressed: bool, pub flashlight_pressed: bool }

pub fn edges(current: &Input, previous: &Input) -> InputEdges;
```

## Notes

The wire format carries **held state only** — no edge flags. Edges are derived here,
identically on the server and in the client's predictor. This is what makes a
dropped input packet harmless: the next packet re-establishes the full truth, where
a lost edge would be gone forever.

`move_dir` returns 0 when both LEFT and RIGHT are held. Preferring one silently
produces a player who drifts when both keys are down, which feels broken. Zero is
the honest answer.

Bit 7 is reserved. Do not use it — T6.06 packs this struct onto the wire and the
layout is fixed in `docs/40-net-protocol.md`.

`Input` is `Copy` and `Default` because the predictor keeps a ring buffer of them
and the first tick needs a zero "previous".

## Tests

- `held` reports each button independently for every single-bit value.
- `move_dir` is −1 for LEFT only, +1 for RIGHT only, 0 for neither, 0 for both.
- `aim_angle` round-trips against `quantize_angle` for a sweep of angles.
- `edges`: jump held last tick and this tick → `jump_pressed` false.
- `edges`: jump not held last tick, held this tick → `jump_pressed` true.
- `edges`: jump held last tick, not held this tick → `jump_released` true.
- `edges` against a `Default` previous input reports a press for every currently
  held button (the first-tick case).
- `Input::default()` has no buttons held and `seq == 0`.
- The reserved bit is never set by any constructor in this file.
