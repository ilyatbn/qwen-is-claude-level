## Deliverable

```rust
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Body {
    pub pos: Vec2,          // CENTRE of the AABB
    pub vel: Vec2,
    pub grounded: bool,
    pub airborne_ticks: u32, // ticks since last grounded; 0 while grounded
}

impl Body {
    pub fn new(pos: Vec2) -> Self;
    pub fn aabb(&self) -> Aabb;                       // PLAYER_W x PLAYER_H
    pub fn aabb_at(&self, pos: Vec2) -> Aabb;         // hypothetical position
    pub fn feet_y(&self) -> f32;
    pub fn in_coyote_time(&self) -> bool;             // airborne_ticks <= COYOTE_TIME * SIM_HZ
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum MoveState { Grounded, Airborne, Jetpack }

/// Derived, never stored. See docs/20-player-movement.md §6.
pub fn move_state(body: &Body, jetpack_active: bool) -> MoveState;
```

## Notes

Position is the **centre**, not the top-left. Every other file in the project
assumes this. Half the collision bugs in a project like this come from two files
disagreeing about the anchor, so it is stated once here and never re-decided.

`move_state` is a free function over derived state rather than a stored field. A
stored mode gets out of sync with `grounded` and produces players permanently stuck
in a jetpack animation they cannot leave. Deriving it makes that impossible.

`airborne_ticks` is a tick count, not a float timer, so coyote time is exact and
frame-rate independent. Increment it in the Y resolver (T2.05), reset to 0 when
grounded.

Do not add jetpack fuel, health or inventory here — `Body` is pure kinematics.
Those belong to `PlayerState` in T4.12.

## Tests

- `aabb()` on a body at (100, 100) has min (92, 86) and max (108, 114) for a
  16×28 box. Assert the exact numbers — this pins the centre-anchor convention.
- `feet_y()` equals `pos.y + PLAYER_H / 2`.
- `in_coyote_time` is true at `airborne_ticks == 0` and at
  `COYOTE_TIME * SIM_HZ` (6), false at 7.
- `move_state` returns `Grounded` when grounded and jetpack is inactive; `Jetpack`
  when the jetpack is active regardless of grounding; `Airborne` otherwise.
- `Body` is `Copy` and equality works (needed by prediction in T6.09).
