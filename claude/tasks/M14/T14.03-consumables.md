# T14.03 — Heals and batteries leave the inventory (v4)

Milestone: M14 · Depends on: T14.02 · Size: ~200 lines

## Read first
- `docs/72-amendments-v4.md` §C9

## Deliverable

`heals: u8` (max **2**) and `batteries: u8` (max **4**) on `PlayerState`, shown as
counters beside the health bar rather than as inventory slots.

- Picking one up increments the counter; **at max the pickup is refused and the item
  stays on the ground**, the same rule as a full inventory (`docs/30` §2).
- **`Q`** uses a heal (`MEDKIT_HEAL`), **`R`** uses a battery (`BATTERY_PACK_AMOUNT`).
  Both are rejected with no effect at zero.
- Snapshot: one byte, `heals` in 2 bits and `batteries` in 3.
  `SNAPSHOT_PLAYER_BYTES` 16 → **17**.

## Notes

- Every codec that reads a player block changes — Rust encoder, Rust decoder **and**
  the TypeScript decoder. §B22: a crate-scoped test passed twice while one of the
  three was missed. Run the gate.
- Size tests pin to the constants, never a literal (§A19/§B22) — a fixture that
  hardcodes the layout stays green against a drifted decoder.
- Death drops: heals and batteries are **not** inventory, so decide deliberately
  whether they drop, and write the reason down.

## Tests

- Pickup at max refuses and leaves the world item in place, with a control proving a
  pickup below max succeeds.
- `Q`/`R` at zero are rejected and change nothing (assert the effect, not the input).
- `Q` at 1 heal heals exactly `MEDKIT_HEAL`, clamped to `HEALTH_CAP`.
- Snapshot round-trips for every combination of the packed byte, and the size is
  exactly `8 + n*17 + 4`.
