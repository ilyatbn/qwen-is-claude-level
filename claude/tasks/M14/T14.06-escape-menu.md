# T14.06 — The escape menu (v4)

Milestone: M14 · Depends on: T13.06 · Size: ~130 lines

## Read first
- `docs/72-amendments-v4.md` §C13

## Deliverable

`Esc` opens a centred menu over the field: **Resume**, **Options** (present, disabled,
"Coming soon"), **Quit to title** (leaves the room and returns to the title screen).
`Esc` closes it.

## Notes

- **It is an overlay, not a pause** — the round keeps running behind it, exactly as
  §B4 established for the death screen and `docs/30` §3 for the inventory.
- `Esc` must not swallow the inventory's `Esc` when that is open: innermost overlay
  first. Test the stacking, because this is where key handling usually breaks.
- Options is disabled and visible, not hidden — the same treatment weapon skins get
  in the skins menu (§B3), so the player knows it is planned.
- Quit must actually leave the room (`leave_room`), not just change scene, or the seat
  stays occupied and the room never reaps.

## Tests

- `Esc` toggles the menu; with the inventory open, `Esc` closes the inventory first
  and the menu second.
- **Quit to title** leaves the room: the old room sends the client nothing further,
  with a control proving events from a newly joined room do arrive.
- The world keeps ticking while the menu is open.
- Options is present, disabled, and not keyboard-focusable.

## Done when

```sh
npm --prefix client test -- --run escapeMenu && node scripts/e2e.mjs escape-menu
```
