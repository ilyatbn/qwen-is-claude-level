# T14.04 — Quick-throw a grenade with E (v4)

Milestone: M14 · Depends on: T14.03 · Size: ~120 lines

## Read first
- `docs/72-amendments-v4.md` §C11

## Deliverable

**`E`** throws a grenade-class item from anywhere in the inventory — the first found,
in the order grenade, molotov, toxic, smoke, airburst — along the aim angle, **without
changing the selected slot**. Rejected with no effect if you have none.

## Notes

- This is what makes twenty weapons usable: you stop losing fights while opening a
  panel.
- It is a **command**, like fire and use (`docs/30` §4), and takes the same validation
  order: alive, has one, cooldown, then throw.
- The search order is fixed and documented, so the same key does the same thing every
  time — a random pick would make it unusable.
- Bots should use it too, or they carry grenades they never throw — but check first
  whether their selection path already covers it rather than assuming (§B19: bots
  could not switch weapons at all for a whole milestone).

## Tests

- `E` with a grenade throws it along the aim angle and decrements that stack.
- `E` with several kinds picks the documented first one.
- `E` with none is rejected and spawns nothing.
- The selected slot is unchanged afterwards.
- Cooldown is respected, and it shares the per-player cooldown so it cannot be used
  to bypass one (`fire_ready_at` is per player by design).
