# T22.08D — Where the flare is drawn

Milestone: M22 · Depends on: **T22.08B** (`8887234`), **T22.08C** · Origin: the harsh review of
`8887234` (2026-09-23), every finding verified with a plant by the reviewer, with the coordinator's

T22.08B shipped a flare that draws and is covered in both render paths. The review found that the
**match** path — the one players see — measures its clock, its burn display and its catch-up through
things other than the server: the signature defect again. Nothing here crashes.

## Do these
- **F1 (HIGH — a guard that cannot fail).** `solar-flare-match` probes the damage points with the
  scene's own `flareQuery`, so a +0.5 s origin offset (~80 px, 6× the contact radius) stays green.
  Expose the **server's own** flare elapsed through a dev hook (`DEV_PROBE=1` → `debug_effects`),
  assert |client elapsed − server elapsed| ≤ one snapshot interval, and show the +0.5 plant red.
- **F2 (MEDIUM — visible).** The origin came off the snapshot round time truncated to 0.1 s
  (`codec.rs::encode_snapshot`), re-set every snapshot: the ribbon went backwards 19 times in 120
  frames. **Ruled:** origin = the effect's start tick × `SIM_DT`, clocked by a smoothed server clock
  sampled from the snapshot **tick** — monotonic. Test: elapsed never decreases over N drawn frames in
  the match; the match also runs GameScene's **shader** path, not only flat.
- **F3 (MEDIUM).** Burning comes from a client contact test on predicted/interpolated positions.
  **Ruled:** local — contact is provisional, flames drop if no `weather` `damage` arrives within
  `SOLAR_FLARE_CONFIRM_SECONDS`, and a `weather` `damage` during a flare starts them without contact.
  Remotes — confirmed by the snapshot health dropping while the flare runs. Local rule tested both ways.
- **F4 (MEDIUM).** Nothing replays a running effect to a joiner. The join path sends the running
  effects through the live `effect_start` / `effect_phase` serializer, original ticks and seeds. Test
  server-side. (Mid-match joins are refused since §E4; this rides with the dormant reconnection
  catch-up and is stated so.)
- **F5 (LOW).** The banner counts 16 s while the ribbon is gone for the last 4 → "BURNING OUT" once
  `flare_lit` is false.
- **F6 (LOW).** `terrain-render`'s layer list lacks −27 (T22.06's sky): add it, run it green, correct
  its `flaky-test.md` row; **leave `flaky: true`** — the owner decides.
- **F7 (LOW).** wasm `flare_for`'s double `get_or_insert_with`; the vacuous `effectLabel('SolarFlare')`
  line; `FlarePoints` / `StrokePass` exported for nobody.
