# T22.00H — `beams-shader` read the sky's morning as a moving stroke

Milestone: M22 (gate hygiene) · Depends on: T22.00F · Size: ~35 lines · Origin: T22.00C's builder
found `beams-shader` red 3/3 at HEAD (*"stroked 75.2% changed … does not animate"*) and put the
regression in `4dfc5a5..2d47a7f`.

## There is no first bad commit

`git bisect run` over `4dfc5a5^..a793e18` with `node scripts/e2e.mjs =beams-shader` as the test
(log: `gate-t2200h-bisect-log.txt`) named `4dfc5a5` (T22.12D) — **only because the good end was
assumed**. Run explicitly, the parent `4ab7a8f` is red the same way (stroked 75.2 %, painted
41.0 %, `gate-t2200h-bisect-4ab7a8f.txt`). Every commit tested, both ends included, reads
**stroked 75.2 %**, the same number to the decimal. The suspect (T22.12D's tick-derived round
clock stopping the shader's `time`) is ruled out as well: the beam shader's `time` is Phaser's
own loop uniform (`ordnance.ts`, the comment at `sh.setUniform('life.value', k)`), and the
painted beam moved 24–42 % in every red run.

**What changed is how the check was run.** Every green `held beam` line in the tree's logs comes
from a batch (`--jobs 4`: 90 frames in 3.2–3.7 s, check 35 s); every red one from `=beams-shader`
alone (90 frames in 1.4 s, check 20 s). Alone, the flicker section reaches its band ~3 s into
the round; in company, ~17 s in (`debug().roundTime` 16.6 → 22.3, measured).

## The cause: the band is sky, and the sky's day cycle runs on the round clock

Dumped band crops, stroked pass: player, camera and zoom identical at every step; the difference
is **the sky**, ~12 per channel over 90 frames (`[110,155,208]` → `[109,162,220]`), in 75.2 % of
the band's pixels. `sky-math.ts` moves the gradient from `KEYFRAMES` 0.0 to 0.12 in the first
`0.12 * CYCLE_LENGTH` s of a round — fastest exactly where the idle run lands — and barely at all
on the 0.12 → 0.3 stretch where the batch run lands. The "still strokes" control was never still;
the batch's slowness hid it.

## The fix

`__game.holdSky(t | null)` (`GameScene.ts`): the sky and its parallax band are drawn at `t`
(`skyHeldAt ?? roundTime` at the one `sky.update` call); darkness, fog and the shader's own
`time` keep the live clock. `beams-shader`'s `flicker` holds the sky at the current round time
across its five steps and releases it. **No threshold touched.**

Plants, alone on an idle box: `sky.update` ignoring the hold → red, stroked 75.2 %
(`gate-t2200h-plant-nohold.txt`); the beam ripple's `time` zeroed in `shaders.ts` → red, painted
0.0 % against 0.0 % (`gate-t2200h-plant-still.txt`).

Other shader checks, alone on an idle box at HEAD before the fix (`gate-t2200h-others-alone.txt`):
`fire-shader`, `explosion-shader`, `smoke-shader`, `fog-shader`, `thrusters`, `solar-flare`,
`black-hole` all green, every flat control 0.0 % — none photographs a band of sky across a
running scene.

`gameScene-reset.test.ts` caught the new field unreset on the first `--changed` run;
`resetForNewRound` clears it.
