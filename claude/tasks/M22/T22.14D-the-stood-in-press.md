# T22.14D — The stood-in press (what the closing review of T22.14A–C found)

Milestone: M22 · Depends on: T22.14C · Size: medium · Origin: the closing review of `7d87531..93aeb4b` (read-only
reviewer; evidence `gate-review2214-*.txt` in the repo root). Every finding red-first (or planted red) before its fix.

## What the review found
- **F1 (MED, player-visible, predates M22).** A jump pressed during a network hiccup. The server stands in for the
  late seqs with the **old** buttons (R89), discards the real inputs when they land, and first sees the press on the
  next seq — a jump a stand-in's length late. The client's correction restores its own `prev_input` at the ack
  (HIGH-1's history), which holds the press, so the replay sees no edge (and the jetpack's hold delay blocks the
  thrust): correction 63.36 px and still 61.02 px off. The reviewer validated the fix — `prev_input` = the buttons the
  server actually stepped at the ack → 2.34 px / 0.00 px. **Fix:** the snapshot carries the local player's stepped
  buttons at the ack (1 byte, per recipient, beside the footer's ack) and `correct_player_state` restores them as the
  previous input. Side-by-side `World` vs `GameCore` unit (shelf fixture, lag 2; on-time control) red first. E2E
  signature: `thrusters-match`'s standard arm (dee holds Space), worst jumps 35–58 px with server speed 0 — re-run 3×,
  before/after.
- **F2 (guard missing).** No weapon-level test that a player's rocket fired into the rim carves it and opens a vortex:
  planting R99's rim despawn for *all* ordnance left everything green. Add it as the control to R99's despawn arm;
  plant red.
- **F3.** `Predictor.relocate` never resets jump / jetpack / airborne ticks, while the server's `step_vortices` /
  `fire_pads` do (T22.14C's filed row) — give it the respawn's reset; test.
- **F4.** `codec.ts::MAP_GENERATOR_MAX = 2` is a hand copy of `MapGenerator::from_u8`.
- **F5.** `seqClock.test.ts`'s `lead = 0.25` is a copy of `MAX_FRAME_DT`; `golden_weather.txt`'s header has the H3
  note inserted mid-sentence.
- **canvas-renderer.** `settle()` took two 100 ms samples < 0.5 px apart as settled, so a stalled frame read as a
  settled camera (1 failure in 22 runs under the full suite). Require rendered frames between samples.
