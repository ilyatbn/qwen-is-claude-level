## As built (2026-09-23)

- **One drawing path for both scenes.** `FlareFx` takes a `FlareQuery` (seed halves + the effect's own
  clock) and asks the core: `flare_points` (the samples the server touches with), `flare_lit` (T22.08C's
  window — the effect's `Active` phase now runs 4 s past the ribbon) and `flare_touches` (the server's
  contact test, for who is burning — `R80`, no wire bit). A match builds the query from `FlareClock`,
  started at `effect_start` **with the origin corrected to the event's own tick**; the sandbox's
  `weatherStep` hands the same query out, so the sandbox checks exercise the match's drawing calls.
- **Look**: HQ is `flareFragment(samples)` — nearest-segment distance over the 48 points, field-aligned
  plasma streaks draining down both legs, three twisting magnetic strands pinned at the footpoints, an
  additive corona; body solid to the contact radius whatever the noise does. Flat/Canvas is six filled
  outlines (`ribbonOutline`; WebGL's thick strokes fanned at every joint) with an **added** corona and
  two twisting threads. Telegraph: a ghost ≤ 0.35. Burning bodies: flame tongues + glow until the burn
  ends, ribbon or not. Shots: `shots/solar-flare-webgl-look-hq-{on,off}.png`, `…-canvas-look-*`,
  `…-burning.png`, `shots/solar-flare-match.png`.
- **Checks**: `solar-flare`, `solar-flare-canvas` (serial), `solar-flare-standard`, and **`solar-flare-match`**
  (standalone, `WEATHER=flare`) — GameScene's path, which no sandbox run reaches (`LavaClock`'s lesson).
  Coverage samples **the core's points off the scene's own query**, not the layer's report, at each sample
  and ±0.8 of the contact radius across it: 144/144 in both paths.
- **`radiation-match` / `thrusters-match`**: both already run `WEATHER=off`; no flare can land in their arms.
