## Deliverable

A headless-Chromium suite that boots the real server and the built client and
plays the game. Every spec ends by writing a screenshot to `e2e/shots/`.

Specs:

1. **sandbox-loads** — `?sandbox=1` renders terrain; the canvas is not a flat
   colour (sample pixels, assert variance).
2. **wasd-moves** — hold `D` for 1 s, the player's x increases; hold `A`, it
   decreases; `Space` increases y velocity then lands; the debug readout confirms.
3. **carve** — click to carve, the terrain pixel count drops, the chunk re-bakes.
4. **fire** — pick up a bazooka, fire, a crater appears and health drops on
   self-damage.
5. **multiplayer** — two browser contexts join the same server, both see two
   players, both masks checksum-match after a fired rocket.
6. **daynight** — force round time to 70 s and 130 s; the sky pixels differ and the
   screenshot at night is measurably darker.

## Notes

- Read game state through a `window.__game` debug handle the client exposes when
  `?e2e=1`, rather than scraping pixels for everything.
- Screenshots are the point on WSL: there is no display, so every failure must be
  diagnosable from `e2e/shots/`.
