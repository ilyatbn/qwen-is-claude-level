## Deliverable

```ts
export class Minimap {
  constructor(scene: Phaser.Scene, mapW: number, mapH: number)
  reveal(x: number, y: number, r: number): void
  setTerrainDirty(): void
  update(playerX: number, playerY: number, others: Array<{x:number;y:number;id:number}>): void
  toggle(): void
}
```

## Notes

- Two textures: a downsampled terrain image (one minimap pixel per
  `mapW / MINIMAP_W` world px, re-baked at most twice a second) and a persistent
  "explored" alpha mask that `reveal` paints into and never clears.
- Terrain is only drawn where explored. Unexplored area is flat dark.
- Remote players show only when inside your current FoV — the minimap must not leak
  information the screen does not already give you.

## Tests (vitest)

- `reveal` marks the expected cells for a known radius and is idempotent.
- Explored area only ever grows.
- World → minimap coordinate mapping is exact at both corners.
- `toggle` flips visibility.
